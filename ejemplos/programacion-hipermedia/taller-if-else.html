Teoría: condición, if, else e if / else

1. ¿Qué es una condición?

Una condición es una expresión que el código evalúa, y cuyo resultado siempre es uno de dos valores posibles: true (verdadero) o false (falso). Para construir una condición se usan los operadores relacionales:

OperadorSignificado
==igual a
!=distinto de
>mayor que
<menor que
>=mayor o igual que
<=menor o igual que
int edad = 20;
bool esMayor = edad >= 18;   // esMayor guarda true

Ojo: un solo = es asignar un valor, y doble == es comparar dos valores. Cualquier expresión que use uno de los operadores de la tabla ya es, por sí sola, una condición que el programa puede evaluar.

2. La instrucción if

if es una palabra reservada de C#. Sirve para ejecutar un bloque de código solo cuando una condición es true. Se escribe así: 

if (condición)
{
    // este código se ejecuta solo si la condición es true
}

Si la condición da false, todo el bloque entre llaves se salta, como si no existiera, y el programa sigue de una vez con la línea siguiente. Ejemplo: 

int edad = 20;

if (edad >= 18)
{
    Console.WriteLine("Es mayor de edad");
}
Importante: usen siempre las llaves { }, aunque el bloque tenga una sola línea adentro. Sin llaves, C# solo asocia el if con la línea inmediatamente siguiente, y eso es una fuente muy común de errores.

3. La instrucción else

El if por sí solo cubre un solo camino: qué hacer cuando la condición es true. La palabra else agrega un segundo camino: qué hacer cuando la condición es false. else no lleva su propia condición, significa simplemente "en cualquier otro caso". 

if (condición)
{
    // se ejecuta si la condición es true
}
else
{
    // se ejecuta si la condición es false
}

Ejemplo:

Console.WriteLine("¿Cuántos años tienes?");
int edad = int.Parse(Console.ReadLine());

if (edad >= 18)
{
    Console.WriteLine("Ya puede votar");
}
else
{
    Console.WriteLine("Todavía no puede votar");
}

De estos dos bloques, siempre se ejecuta exactamente uno: nunca los dos al mismo tiempo, y nunca ninguno.

4. if / else juntos: tomando una decisión completa

Cuando se combinan if y else, el programa cubre las dos posibilidades de una condición: qué pasa si se cumple, y qué pasa si no. Esta es la estructura más común para tomar decisiones simples en el código: evaluar algo, y según el resultado, seguir por un camino o por el otro.

Antes de empezar con los ejercicios: primero piensen qué condición necesitan evaluar y con qué operador de la tabla, y después escriban el if/else alrededor de esa condición. No hace falta memorizar nada, pueden volver a esta página en cualquier momento.

Ejercicios

Grupo 1 — Un solo camino (if)
Ejercicios donde solo hace falta avisar algo cuando se cumple una condición.
1

Tienen guardada la velocidad de un carro en km/h. Si esa velocidad supera el límite de 60 km/h, el programa debe alertar que va muy rápido.

2

Tienen guardado el saldo de una tarjeta prepago de transporte. Si ese saldo es menor a $2.000, el programa debe avisar que hay que recargar.

3

Tienen guardada la cantidad de vidas que le quedan a un personaje de videojuego. Si esa cantidad llega a cero, el programa debe mostrar en pantalla "Game Over".

Grupo 2 — Dos caminos (if / else)
Ejercicios donde el programa siempre debe decir algo, sea cual sea el resultado.
4

Tienen guardado el año de nacimiento de alguien. El programa debe decir si esa persona ya es mayor de edad o todavía no.

5

Tienen guardada la nota final de un estudiante, de 0 a 5. El programa debe decir si esa materia quedó aprobada o perdida (la nota mínima para aprobar es 3.0).

6

Tienen guardados dos números enteros distintos. El programa debe decir cuál de los dos es el menor.

7

Tienen guardado un número entero. El programa debe decir si ese número es divisible por 3 o no.

Grupo 3 — Combinando operadores
Ejercicios que mezclan operadores aritméticos y relacionales dentro de un if / else.
8

Tienen guardado el precio de un producto, y si el cliente tiene cupón de descuento (true o false). Si tiene cupón, muestren el precio con un 20% de descuento aplicado; si no, muestren el precio normal.

9

Tienen guardada la hora del día en formato 24 horas (un número entero de 0 a 23). El programa debe decir si en este momento es de día o de noche (consideren de día entre las 6 y las 18).

10

Tienen guardados el número de entradas que alguien quiere comprar para el cine y el precio de cada entrada. Calculen el total a pagar, y díganle si ese total supera los $50.000, caso en el que aplica para combo gratis.

11

Tienen guardados dos números enteros. El programa debe calcular su suma y decir si esa suma es un número par o impar.

Reto extra (opcional)
Para quien termine antes y quiera ir más allá: estos ejercicios necesitan encadenar más de una condición (else if) o combinar condiciones con operadores lógicos (&& / ||), algo que ya alcanzamos a ver por encima en la clase pasada.
12

Tienen guardada la cantidad de puntos que sacó un jugador en una prueba, de 0 a 100. El programa debe decir si el resultado es "Oro" (90 o más), "Plata" (70 a 89), "Bronce" (50 a 69) o "Sin medalla" (menos de 50).

13

Tienen guardadas la edad de una persona y si va acompañada de un adulto (true o false). El programa debe decir si esa persona puede entrar a ver una película con clasificación +15: sin compañía necesita 15 años o más, pero acompañada puede entrar desde los 13.

14

Tienen guardados el clima de hoy como texto ("soleado", "lluvia" o "nublado") y la temperatura. El programa debe recomendar qué llevar: paraguas si está lloviendo, gafas de sol si está soleado y hace más de 25 grados, o nada especial en cualquier otro caso.
