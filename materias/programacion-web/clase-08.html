Materiales
El material define de qué color es
la superficie y cómo reacciona a la luz
Ya conocemos uno
const material = new THREE.MeshBasicMaterial({
  color: 0xff5fc4
});
Color plano. No le importa la luz
Los materiales se configuran con un objeto de opciones 
new THREE.MeshBasicMaterial({
  color: 0xff5fc4,
  wireframe: true,   // solo las aristas
  visible: true      // false = no se dibuja
});
Transparencia: se usan dos opciones juntas 
new THREE.MeshBasicMaterial({
  color: 0xffffff,
  transparent: true,
  opacity: 0.4
});
¿Qué pasa si pongo opacity: 0.4
pero se me olvida transparent: true?
Nada. Se ve totalmente opaco
side: ¿desde qué lado se ve la cara? 
new THREE.MeshBasicMaterial({
  color: 0x5ff0d0,
  side: THREE.DoubleSide   // por defecto: FrontSide
});
Un plano con el lado por defecto
desaparece si lo miras por detrás

Con DoubleSide se ve por los dos lados
MeshNormalMaterial: un material para depurar
pinta cada cara según hacia dónde mira 
new THREE.MeshNormalMaterial();
Y todo se puede cambiar en vivo 
cubo.material.color.set(0x00ff00);
cubo.material.wireframe = true;
cubo.material = otroMaterial;
MeshBasicMaterial = plano, no necesita luz

Todos los demás materiales
necesitan luz para verse

Luces
Un material con luz,
en una escena sin luces,
se ve negro 
const material = new THREE.MeshStandardMaterial({ color: 0xff5fc4 });
// sin luces en la escena = esfera negra
AmbientLight: ilumina todo por igual, sin dirección 
const ambiente = new THREE.AmbientLight(0xffffff, 0.4);
scene.add(ambiente);
DirectionalLight: como el sol, rayos paralelos 
const sol = new THREE.DirectionalLight(0xffffff, 2);
sol.position.set(3, 4, 5);
scene.add(sol);
PointLight: como una bombilla, ilumina desde un punto 
const foco = new THREE.PointLight(0xffffff, 60);
foco.position.set(0, 3, 2);
scene.add(foco);
Se debilita con la distancia: por eso necesita valores altos
Los materiales con luz
MeshLambertMaterial
Mate. Barato de calcular. Sin brillo 
new THREE.MeshLambertMaterial({ color: 0xff5fc4 });
MeshPhongMaterial
Agrega un brillo (reflejo de la luz) 
new THREE.MeshPhongMaterial({
  color: 0xff5fc4,
  shininess: 90,       // qué tan concentrado es el brillo
  specular: 0xffffff   // color del brillo
});
Los cinco con la misma luz. Miren las diferencias
MeshStandardMaterial
El material "serio": usa PBR
(Physically Based Rendering) 
new THREE.MeshStandardMaterial({
  color: 0xff5fc4,
  roughness: 0.4,
  metalness: 0
});
MeshPhysicalMaterial
Standard + extras: barniz, vidrio, iridiscencia 
new THREE.MeshPhysicalMaterial({
  color: 0xff5fc4,
  roughness: 0.4,
  clearcoat: 1,            // capa de barniz encima
  clearcoatRoughness: 0.05
});
Del más barato al más realista
Basic → Lambert → Phong → Standard → Physical

Más realismo = más trabajo para la tarjeta gráfica
Pregunta: ¿qué material usarían
para las bolas de billar?
Physical con clearcoat:
son bolas de resina con barniz
PBR: dos perillas
roughness (rugosidad)

0 = espejo liso
1 = totalmente mate
metalness

0 = no metal (plástico, madera, tela)
1 = metal puro
Jueguen con las dos perillas
Regla práctica
Plástico, madera, tela: metalness 0
Oro, plata, acero: metalness alto (0.7 a 1)

Texturas
Una textura es una imagen
que se pega sobre la superficie 
const cargador = new THREE.TextureLoader();
const textura = cargador.load("madera.jpg");

const material = new THREE.MeshStandardMaterial({
  map: textura
});
Si los colores se ven lavados,
falta decirle a Three.js que la imagen es de color 
textura.colorSpace = THREE.SRGBColorSpace;
Texturas de prueba (ya subidas a internet)
uv_grid_opengl.jpg (una cuadrícula)
hardwood2_diffuse.jpg (madera)
brick_diffuse.jpg (ladrillo)

La ruta base ya viene en la plantilla:
TEXTURAS + "hardwood2_diffuse.jpg"
Para repetir la textura en mosaico 
textura.wrapS = THREE.RepeatWrapping;
textura.wrapT = THREE.RepeatWrapping;
textura.repeat.set(4, 4);   // 4 veces en X, 4 en Y
Cambien la repetición, el modo de envoltura y el desplazamiento
Si cambian el wrap después de cargar,
hay que avisarle a Three.js 
textura.wrapS = THREE.MirroredRepeatWrapping;
textura.needsUpdate = true;
Además del color existen otros mapas 
map: colorTextura,
normalMap: relieveTextura,       // relieve falso con luz
roughnessMap: rugosidadTextura   // rugosidad distinta por zona
Hoy nos quedamos con map
Ojo: PlaneGeometry nace parado
Para un piso hay que acostarlo 
piso.rotation.x = -Math.PI / 2;
