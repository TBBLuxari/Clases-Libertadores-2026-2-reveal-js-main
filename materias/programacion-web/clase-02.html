HTML
Repaso y estructura semántica
La clase pasada escribimos esto: 
<!DOCTYPE html>
<html>
<body>
  <h1>Hola mundo</h1>
</body>
</html>
Eso ya era HTML válido
pero le faltan piezas que siempre
vamos a usar 
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <title>Mi página</title>
</head>
<body>
</body>
</html>
head
Metadatos: cosas que el navegador necesita
pero que nadie ve en pantalla
body
Todo lo que sí se ve
en la página
Cada etiqueta puede tener
otras etiquetas adentro
Eso arma un árbol:
padres, hijos, hermanos 
<body>
  <div>
    <div>
      <div>Hola</div>
    </div>
  </div>
</body>
Esto también es válido...
...pero no le dice nada a nadie
ni al navegador, ni a un lector de pantalla,
ni a Google

Un div no dice si es
un menú, un botón o el pie de página
Por eso existe el HTML semántico
HTML semántico
Etiquetas que describen su función,
no solo una caja genérica
Las etiquetas semánticas más usadas
header
nav
main
section
article
aside
footer
header
La cabecera de la página
o de una sección (logo, título, menú)
nav
Los enlaces de navegación
(menú principal, migas de pan)
main
El contenido principal
único por página, no se repite
section
Un bloque temático
con un propósito propio
article
Contenido que podría vivir solo
(un post, una noticia, una tarjeta de producto)
aside
Contenido relacionado pero secundario
(una barra lateral, un dato curioso)
footer
El pie de la página
o de una sección 
<body>
  <header>...</header>
  <nav>...</nav>
  <main>
    <section>...</section>
    <article>...</article>
  </main>
  <aside>...</aside>
  <footer>...</footer>
</body>
¿Y si nada de eso encaja?
ahí sí se vale usar div
Regla simple: semántico primero,
div solo cuando no hay una etiqueta mejor

CSS
Selectores y box model
Ahora sí, vamos a darle
apariencia a lo que ya construimos
Hay tres formas de conectar CSS
a un HTML
1. Inline 
<h1 style="color: hotpink;">Hola</h1>
Evitar: mezcla estructura y apariencia
2. Etiqueta style 
<head>
  <style>
    h1 { color: hotpink; }
  </style>
</head>
Ya la vimos la clase pasada
3. Archivo externo 
<head>
  <link rel="stylesheet" href="estilos.css">
</head>
Esta es la que vamos a usar hoy
Separar HTML y CSS en archivos
distintos es más ordenado
y más fácil de mantener
Selectores
Cómo le decimos al CSS
a qué le va a aplicar el estilo
Por etiqueta 
h1 {
  color: hotpink;
}
Aplica a todos los h1
Por clase 
.tarjeta {
  color: hotpink;
}
<div class="tarjeta">...</div>
Una clase se puede reutilizar
en muchos elementos distintos
Por id 
#principal {
  color: hotpink;
}
<div id="principal">...</div>
Un id es único,
solo un elemento por página
Regla práctica: casi siempre clase,
id solo para casos muy puntuales
Box model
Todo elemento en HTML
es, para el navegador, una caja

Aunque no se vea, siempre hay una caja
Esa caja tiene 4 capas
content
El texto o contenido real
del elemento
padding
Espacio adentro,
entre el contenido y el borde
border
El borde de la caja,
puede tener grosor, color y estilo
margin
Espacio afuera,
entre esta caja y las demás 
.tarjeta {
  padding: 20px;
  border: 2px solid hotpink;
  margin: 16px;
}
Truco importante
Por defecto, padding y border
se suman al ancho que pusiste 
.caja {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  /* ancho real: 250px, no 200px */
}
¿Por qué 250px y no 200px?
El padding y el border se cuentan
por cada lado, dos veces
Al tablero

200px (width del content)
+ 20px + 20px (padding izquierdo y derecho)
+ 5px + 5px (border izquierdo y derecho)
= 250px de ancho real en pantalla
Y esto pasa en cada dirección:
también le suma alto si le pones
padding/border arriba y abajo
Para evitar esa sorpresa:
box-sizing: border-box 
* {
  box-sizing: border-box;
}
Ahora padding y border quedan adentro
del width que definiste
Desde hoy, siempre van a empezar
su CSS con esa regla
A programar, otra vez
Vuelvan a su archivo de la landing del evento
Creen un archivo nuevo:
estilos.css
en la misma carpeta
Al tablero

<head>
  <link rel="stylesheet" href="estilos.css">
</head>
Conectamos el archivo 
* {
  box-sizing: border-box;
}

body {
  margin: 0;
  font-family: sans-serif;
}
Esto va primero, siempre
Paso 1: denle un color de fondo
al header con background-color 
header {
  background-color: #2a2140;
  padding: 20px;
}
Paso 2: al nav, pongan
los enlaces en fila con display: flex 
nav {
  display: flex;
  gap: 16px;
}
De flexbox hablamos más a fondo la próxima clase
Paso 3: a cada article de la agenda,
denle padding, border y margin 
article {
  padding: 16px;
  border: 1px solid #ccc;
  margin: 10px 0;
  border-radius: 6px;
}
Paso 4: centren el contenido
del main y limítenle el ancho 
main {
  max-width: 700px;
  margin: 0 auto;
  padding: 20px;
}
margin: 0 auto centra una caja
que ya tiene un ancho definido
Paso 5: denle color y tamaño
de letra a los h1, h2 y h3 
h1 { color: white; }
h2 { color: #2a2140; }
h3 { color: #555; font-size: 1.1rem; }
Reto final de la clase
Con lo que ya saben, personalicen
los colores, dénle estilo al footer
y a los enlaces del nav
