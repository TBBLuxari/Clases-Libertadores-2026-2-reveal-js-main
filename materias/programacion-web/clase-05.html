La clase pasada vimos condicionales (if / else)
y ciclos (for)
Hoy: funciones bloques de código
reutilizables, con nombre
Sintaxis básica 
function saludar(nombre) {
  console.log("Hola " + nombre);
}

saludar("Ana");
nombre es el parámetro (lo que recibe)
"Ana" es el argumento (lo que se manda)
return 
function sumar(a, b) {
  return a + b;
}

let total = sumar(3, 4); // 7
Sin return: la función devuelve undefined
Con return: devuelve el valor, y corta ahí la función
Tipos de función
Declarada 
function sumar(a, b) {
  return a + b;
}
Expresión (guardada en una variable) 
const sumar = function (a, b) {
  return a + b;
};
Función flecha (arrow function) 
const sumar = (a, b) => {
  return a + b;
};
Si el cuerpo es una sola línea con return,
se puede escribir aún más corto 
const sumar = (a, b) => a + b;

Ejercicio 2: función potencia(base, exponente)
que calcule base elevado a exponente,
usando un for
Recursión
Ya armaron potencia(base, exponente) con un for.
Ahora la misma función, pero de manera recursiva
De forma recursiva 
function potencia(base, exponente) {
  if (exponente === 0) {
    return 1;
  }
  return base * potencia(base, exponente - 1);
}
El if (exponente === 0) es el caso base
sin eso, la función se llamaría a sí misma para siempre
for: repite el mismo bloque N veces
Recursión: la función se llama a sí misma,
achicando el problema cada vez hasta llegar al caso base
Las dos formas llegan al mismo resultado
hay problemas donde la recursión se lee más natural
(ej. recorrer árboles, carpetas dentro de carpetas)
Ejercicio 3: función sumarRango(n)
que sume del 1 al n háganla con for primero,
y después de forma recursiva
Sin recursión 
function sumarRango(n) {
  let total = 0;
  for (let i = 1; i <= n; i++) {
    total = total + i;
  }
  return total;
}
Con recursión 
function sumarRango(n) {
  if (n === 0) {
    return 0;
  }
  return n + sumarRango(n - 1);
}
this y el contexto
this apunta a "quién llamó la función" —
depende de cómo se llama, no de dónde se escribió
Función normal como método 
const persona = {
  nombre: "Ana",
  saludar: function () {
    console.log("Hola, soy " + this.nombre);
  }
};

persona.saludar(); // "Hola, soy Ana"
Mismo objeto, con función flecha 
const persona = {
  nombre: "Ana",
  saludar: () => {
    console.log("Hola, soy " + this.nombre);
  }
};

persona.saludar(); // "Hola, soy undefined"
Las funciones flecha no tienen su propio this
heredan el del lugar donde fueron escritas
Por eso, para métodos de un objeto se usa
función normal para callbacks
(ej. dentro de un evento)
suele preferirse función flecha
Hoisting 
saludar(); // funciona, imprime "Hola"

function saludar() {
  console.log("Hola");
}
Las funciones declaradas se "elevan" (hoisting)
antes de que el código empiece a correr por eso se puede
llamar la función antes de escribirla 
saludar(); // Error: no se puede usar antes de declararla

const saludar = () => {
  console.log("Hola");
};
Con const / let esto NO pasa igual
la variable existe pero no se puede usar todavía
Función: bloque de código reutilizable, con parámetros y return
3 formas de escribirla: declarada, expresión, flecha
Recursión: una función que se llama a sí misma,
siempre con un caso base
this: depende de cómo se llama la función
las flecha no tienen this propio
Hoisting: las funciones declaradas se pueden llamar
antes de escribirlas,
las guardadas en variable no
