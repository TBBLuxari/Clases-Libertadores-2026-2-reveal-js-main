Funciones
Hasta ahora, cada vez que necesitábamos hacer algo,
escribíamos el código otra vez
Una función guarda un bloque de código
bajo un nombre, para reutilizarlo cuantas veces queramos
Sintaxis básica 
function saludar() {
  console.log("Hola");
}
Vamos a desarmarla pieza por pieza 
function saludar() {
  console.log("Hola");
}
function es la palabra reservada
le dice a JavaScript: "voy a crear una función" 
function saludar() {
  console.log("Hola");
}
saludar es el nombre que nosotros elegimos
(mismas reglas que los nombres de variables) 
function saludar() {
  console.log("Hola");
}
Los ( ) van después del nombre
por ahora los dejamos vacíos, ya vienen los parámetros 
function saludar() {
  console.log("Hola");
}
Y las { } son el cuerpo
todo lo que la función hace cuando se ejecuta
Importante
Escribir la función no la ejecuta todavía
solo la deja lista para usarse
Error común: pensar que el código de adentro corre apenas se declara la función. Solo corre cuando uno la LLAMA.
Para ejecutarla, hay que llamarla por su nombre 
function saludar() {
  console.log("Hola");
}

saludar();
Al tablero

Con el código anterior, si borráramos la línea
saludar();, ¿qué pasaría?
Nada, la función nunca se ejecuta
Parámetros
Son datos que la función recibe
para trabajar con ellos 
function saludar(nombre) {
  console.log("Hola " + nombre);
}
nombre es un parámetro:
una variable que solo existe adentro de la función 
saludar("Ana");
saludar("Luis");
Cada vez la llamamos con un valor distinto
Una distinción importante
Parámetro: el espacio que lo recibe (nombre)
Argumento: el valor real que se manda ("Ana")
Una función puede tener varios parámetros,
separados por coma 
function sumar(a, b) {
  console.log(a + b);
}

sumar(3, 4);

Con el código anterior, ¿qué imprime sumar(10, 5)?

¿Qué devuelve una función?
Hasta ahora, adentro de la función solo
imprimíamos con console.log
Pero console.log solo muestra algo en pantalla
no le entrega ningún valor al resto del programa
Función sin retorno 
function saludar() {
  console.log("Hola");
}

let resultado = saludar();
console.log(resultado);
Al tablero

¿Qué imprime la última línea, console.log(resultado)?
undefined — la función no devolvió ningún valor
Función con retorno
Para devolver un valor usamos la palabra reservada
return 
function sumar(a, b) {
  return a + b;
}
return sí entrega el valor hacia afuera
se puede guardar en una variable 
let total = sumar(3, 4);
console.log(total);   // 7
Importante
return corta la función ahí mismo
nada de lo que esté después se ejecuta 
function ejemplo() {
  return 1;
  console.log("esto nunca se imprime");
}
Al tablero

Con el código anterior, ¿se llega a imprimir
"esto nunca se imprime"?
No, el return corta la función antes de llegar ahí
Repaso rápido
Sin return: la función devuelve undefined
Con return: la función devuelve el valor que uno decida

Funciones recursivas
Una función recursiva es una función que
se llama a sí misma 
function cuentaRegresiva(n) {
  if (n <= 0) {
    console.log("Despegue!");
    return;
  }
  console.log(n);
  cuentaRegresiva(n - 1);
}
Cada vez se llama a sí misma con un valor más chico,
acercándose de a poco a terminar
El if (n <= 0) es el caso base
lo que hace que la función se detenga
Sin caso base, la función se llamaría a sí misma para siempre y el programa se cuelga (stack overflow). El caso base es lo más importante de la recursión.
Al tablero

¿Qué imprime cuentaRegresiva(3)?
3, 2, 1, "Despegue!"
Por ahora solo la vamos a reconocer y entender
más adelante van a escribir más de estas

Revisión
Función: un bloque de código reutilizable,
con nombre, parámetros y cuerpo
Parámetros: los datos que la función recibe
para trabajar con ellos
return: lo que la función devuelve
(o undefined si no hay return)
Recursión: una función que se llama a sí misma,
siempre con un caso base
