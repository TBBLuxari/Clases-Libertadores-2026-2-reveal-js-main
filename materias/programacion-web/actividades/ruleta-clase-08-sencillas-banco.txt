PROGRAMACIÓN WEB, RULETA DE REPASO "SENCILLAS" (CLASE 8)
Total: 77 ejercicios (59 normales de 8 min y 18 difíciles de 10 min). 31 de JavaScript y 46 de Three.js.
Cada ejercicio vale 1 punto: lleva UN solo punto de control, que es lo que debe verse o salir.

===============================================================================
ALCANCE
===============================================================================

SÍ entra (lo que ya se dictó):
- JavaScript puro, en consola: variables (let/const), operadores (aritméticos, %, comparación,
  lógicos), rangos con && (entre un mínimo y un máximo), if / else if / else, for, funciones
  (declarada y flecha, parámetros, return).
- Three.js: Scene/Camera/Renderer, geometrías (Box, Sphere, Plane, Cylinder, Cone, Torus), position/rotation,
  loop animar(), color/wireframe/transparent/opacity/side, MeshNormalMaterial, Basic/Lambert/
  Phong/Standard, luces (Ambient/Directional/Point), roughness y metalness, scene.background.

NO entra: arreglos, .length, métodos de texto, Math.*, while, recursión ni texturas.

CÓMO USARLO
- Los 46 ejercicios de Three.js se hacen sobre ejemplos/programacion-web/plantilla-clase-08.html
  (trae Scene, Camera, Renderer y el loop animar(), pero NINGUNA luz: agregarla es parte del reto
  cuando el ejercicio la pide). Los 31 de JavaScript se hacen en consola o en un script.
- Pegar el contenido de ruleta-clase-08-sencillas-preguntas-una-linea.txt en "editar banco de
  preguntas" de ejemplos/programacion-web/ruletaparcial.html.
- Este archivo está ordenado por el número que muestra la ruleta ("Pregunta N"): cuando salga una
  pregunta, buscan el mismo número aquí y ven la solución de referencia y qué debe verse.
- Nivel oculto: 0 espacios al final = normal, 2 espacios = difícil. NO hay preguntas fáciles
  (marca de 1 espacio), así que los aplicados reciben normales casi siempre y los tramposos reciben
  difíciles casi siempre, sin tocar la ruleta. Los niveles están REVUELTOS para que el número de
  la pregunta no delate la dificultad. Si pegan la lista en un editor que borra los espacios al
  final de cada línea, se pierden las marcas.
- Calificación: cada pregunta trae UN punto de control (lo que debe verse o salir), con la
  función que la ruleta ya tiene. Después del intento: "Calificar" (Alt+R), tecla 1 para
  marcarlo y Enter. Queda "1 de 1" o, si no lo marcan, "0 de 1". La ruleta no se modificó.
- Si la ruleta ya tenía otras preguntas guardadas en el navegador, usen "Reiniciar" o peguen la
  lista a mano.

Pregunta 2  [DIFÍCIL, JavaScript, 10 min]  (JS-D2)
Escriban una función factorial(n) usando un for (el factorial de 4 es 4 x 3 x 2 x 1), y muestren en consola los factoriales del 1 al 6.
  Debe verse / salir: Salen 1, 2, 6, 24, 120 y 720.
  Referencia:
    function factorial(n) {
      let r = 1;
      for (let i = 2; i <= n; i++) {
        r *= i;
      }
      return r;
    }
    for (let k = 1; k <= 6; k++) {
      console.log(factorial(k));
    }
