Variables
Una variable es un espacio en memoria
donde guardamos un valor
Piénsenla como una caja con nombre
adentro guarda algo: un número,
un texto, lo que sea 
let nombre = "Juan";
Esto crea una caja llamada "nombre"
Con el valor "Juan" guardado adentro
Para declarar una variable usamos
una palabra clave: let, const o var
let
Declara una variable que sí se puede
reasignar más adelante 
let edad = 20;
edad = 21;
// funciona, no hay error
const
Declara una variable constante
no se puede reasignar después 
const PI = 3.1416;
PI = 3; // Error: Assignment to constant variable
Regla práctica: usen let por defecto,
y const solo si el valor no va a cambiar
var
La forma antigua de declarar variables
hoy casi no se usa
Se comporta distinto a let/const en cosas
que vamos a ver más adelante (scope)
por ahora: evítenla
Nombres de variables
Descriptivos y en camelCase:
edadUsuario, no e ni Edad_Usuario
Bien: nombreCompleto, precioTotal, esActivo
Mal: x, dato1, 2personas
Partes de una variable 
let edad = 20;
Vamos a desarmar esta línea
pieza por pieza 
let edad = 20;
let es la palabra reservada
le dice a JavaScript: "voy a crear una caja nueva" 
let edad = 20;
edad es el nombre
que nosotros elegimos para esa caja 
let edad = 20;
El signo = aquí no es "igual" matemático
significa "guarda esto adentro" 
let edad = 20;
Y el 20 es el valor
lo que de verdad queda guardado en la caja 
let edad = 20;
Por último, el ;
le dice a JavaScript "esta instrucción terminó aquí"
Entonces, en resumen
palabra reservada + nombre + = + valor + ;
Importante
Esa asignación pasa una sola vez
en el momento en que corre esa línea
No es una regla que la computadora
vuelve a revisar sola todo el tiempo
Error común: pensar que la variable "escucha" cambios y se actualiza sola, o que se le puede decir "solo asigna esto si se cumple algo" sin un if.
Esto sí funciona: asignar directamente
el resultado de una expresión, ya evaluada
Esto todavía no: que el valor dependa
de una acción, o que aplique "solo a veces" 
const esMayorDeEdad = edad >= 18;
// esto sí: guarda el resultado de la comparación, ya evaluado
Eso de "revisar todo el tiempo" o
"solo si se cumple algo" necesita funciones
y condicionales, que vienen más adelante
Nombres que NO se pueden usar
No puede ser una palabra reservada
(let, const, var, function, if...) 
let let = 5;   // Error
No puede empezar con un número 
let 2personas = 5;   // Error
No puede tener espacios ni símbolos raros
solo letras, números, _ y $ 
let mi variable = 5;   // Error

Tipos de dato
Cada variable guarda un valor,
y ese valor tiene un tipo
number
Números, enteros o decimales
en JS no hay una diferencia entre ellos 
let edad = 20;
let precio = 9.99;
string
Texto, siempre entre comillas
simples, dobles o backticks 
let nombre = "Ana";
let ciudad = 'Bogotá';
boolean
Solo dos valores posibles:
true o false 
let esMayor = true;
let tieneDescuento = false;
También existen undefined y null
undefined
Una variable declarada pero sin valor
todavía
null
Una variable vacía a propósito
"aquí no hay nada, y así lo decidí yo"
Para saber el tipo de un valor
usamos typeof 
typeof "Ana";   // "string"
typeof 20;      // "number"
typeof true;    // "boolean"
Al tablero

¿Qué tipo es "25" (con comillas)?
¿Y 25 (sin comillas)?
"25" con comillas es string, 25 sin comillas es number. Buen momento para mostrar que las comillas cambian todo, aunque se "vea" igual.
Operadores
Aritméticos
+ - * / funcionan como
en cualquier calculadora 
5 + 3;   // 8
5 - 3;   // 2
5 * 3;   // 15
5 / 3;   // 1.666...
También existe %, el módulo
el residuo de una división 
7 % 2;   // 1
// 7 ÷ 2 = 3, y sobra 1
Sin correr código todavía:
¿cuánto da 10 % 3?
¿Y 8 % 2?
De comparación
Comparan dos valores y devuelven
true o false 
3 > 2;    // true
3 < 2;    // false
También existen >= y <=
mayor o igual, menor o igual
Para igualdad hay dos operadores:
== y === 
"5" == 5;    // true  (compara solo el valor)
"5" === 5;   // false (compara valor Y tipo)
Regla práctica: usen siempre ===
evita sorpresas raras
Lógicos
Sirven para combinar
varias comparaciones a la vez
&& (and)
Da true solo si ambas
condiciones son verdaderas 
3 > 2 && 5 > 1;   // true
3 > 2 && 5 < 1;   // false
|| (or)
Da true si al menos una
condición es verdadera 
3 > 2 || 5 < 1;   // true
3 < 2 || 5 < 1;   // false
! (not)
Invierte el valor:
true pasa a false, y al revés 
!true;         // false
!(3 > 2);      // false
&& → las dos verdaderas
|| → al menos una verdadera
! → invierte el resultado
A programar, otra vez
Al tablero

Vamos a resolver juntos, en consola 
const a = 10;
const b = 3;
console.log(a + b, a - b, a * b, a / b, a % b);
Ahora con expresiones lógicas:
vamos a evaluar si alguien es mayor de edad 
const edad = 17;
const esMayorDeEdad = edad >= 18;
console.log(esMayorDeEdad);   // false
Y ahora combinándolas con && 
const edad = 20;
const tieneEntrada = true;
console.log(edad >= 18 && tieneEntrada);   // true
