Las 3 piezas base
Toda escena en Three.js necesita tres cosas:
Scene, Camera y Renderer
Scene
La Scene es el contenedor
todo lo que existe en el mundo
3D vive adentro de ella 
const scene = new THREE.Scene();
¿Qué creen que se ve si nunca agregamos nada
a la escena?
Nada está vacía, no hay error, simplemente no hay nada que dibujar
Camera
La Camera define desde dónde y cómo vemos la escena 
const camera = new THREE.PerspectiveCamera(
  75,                                    // fov
  window.innerWidth / window.innerHeight, // aspect
  0.1,                                   // near
  1000                                   // far
);
camera.position.z = 5;
fov: qué tanto "abarca" la cámara
aspect: ancho / alto de la pantalla
near / far: qué tan cerca y qué tan lejos se alcanza a ver
Renderer
El Renderer es el que dibuja la escena, cuadro a cuadro 
const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);
El renderer crea un <canvas>
y lo mete en la página ahí es donde se ve todo 
import * as THREE from "three";

const scene = new THREE.Scene();

const camera = new THREE.PerspectiveCamera(
  75, window.innerWidth / window.innerHeight, 0.1, 1000
);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

renderer.render(scene, camera);
Con esto ya tenemos una escena... vacía.

Geometrías básicas
Para que se vea algo en la escena, necesitamos un Mesh:
geometría (la forma) + material (cómo se ve)
BoxGeometry
const geometria = new THREE.BoxGeometry(1, 1, 1);
// ancho, alto, profundidad
SphereGeometry
const geometria = new THREE.SphereGeometry(1, 32, 32);
// radio, segmentos horizontales, segmentos verticales
PlaneGeometry
const geometria = new THREE.PlaneGeometry(5, 5);
// nace parada, mirando hacia la cámara
El MeshBasicMaterial es el más simple:
un color plano, no necesita luces en la escena 
const material = new THREE.MeshBasicMaterial({ color: 0xff5fc4 });
Mesh = geometría + material, ya listo
para agregar a la escena 
const cubo = new THREE.Mesh(geometria, material);
scene.add(cubo);
Con position, rotation y scale
movemos, giramos y escalamos el mesh 
cubo.position.set(2, 0, 0);
cubo.rotation.x = 0.5;
cubo.scale.set(1.5, 1.5, 1.5);
Si no se ve nada, casi siempre
es una de dos cosas:
olvidar scene.add()
o la cámara mirando para otro lado
El loop de animación
renderer.render() dibuja un solo cuadro.
Para animar, necesitamos dibujar muchos cuadros por segundo 
function animar() {
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(animar);
setAnimationLoop le dice al renderer
que llame esa función automáticamente en cada cuadro
(normalmente 60 veces por segundo)
Adentro del loop podemos cambiar rotation cada cuadro
un poquito cada vez se ve como que gira 
function animar() {
  cubo.rotation.x += 0.01;
  cubo.rotation.y += 0.01;
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(animar);
