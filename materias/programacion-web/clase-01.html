¿Qué es programar?
Programar es
Dar instrucciones precisas a un computador
Programar es como :
seguir una receta de cocina
Pasos en orden → resultado
Sin interpretar intenciones
Programar es completar toda la lógica
que le falta a un computador
Hay que explicarle todo
porque no tiene sentido común
¿Y eso cómo se hace?
Con un algoritmo
¿Qué es un algoritmo?
Una secuencia de pasos ordenados
para resolver un problema o una tarea

Si un paso es ambiguo, el computador se rompe

El boom del punto com
A finales de los 90, todo el mundo
quería tener una página web

Así se veían la mayoría

Este sitio sigue sin cambios desde 1996
Apareció HTML
(HyperText Markup Language)
HTML NO es un lenguaje de programación
es un lenguaje de marcado
como Markdown o LaTeX
Al principio no existía la separación
que vamos a ver más adelante (frontend, backend...)
Todo estaba mezclado
incluso los estilos
Eso hacía que construir un solo sitio
fuera mucho más complejo, tedioso y difícil
Después llegó CSS
para separar la apariencia
de la estructura
CSS también evolucionó
hoy existen preprocesadores y frameworks
como SASS, LESS o Tailwind
Y con el tiempo, HTML también
siguió evolucionando hasta HTML5
Así fue evolucionando (google.com)

Frontend vs Backend
Frontend
Todo lo que el usuario ve
y con lo que interactúa
Ejemplo
Menú de navegación
Imagen / banner principal
Botón
Pie de página
Todo lo marcado en rojo es frontend
Backend
Lo que pasa detrás
servidores, bases de datos
Ahí se resuelve toda la matemática
y la lógica pesada
Ordenamiento de datos, contraseñas
y criptografía
En este curso nos quedamos
en el frontend
Van a escuchar la palabra API
por ahora, solo sepan que existe
Compilado vs interpretado
Compilado
Se traduce todo antes
de poder ejecutarse
Antes de correr, ya detectó muchos errores
es más robusto
Pero toma más tiempo
antes de poder ejecutarse
Interpretado
Se ejecuta línea por línea,
en el momento
No hay que esperar a compilar
se ejecuta al instante
Pero los errores solo aparecen
cuando corre esa línea
Transpilado
Se convierte de un lenguaje
a otro antes de correr
→
También toma tiempo,
como el compilado
Pero permite escribir con sintaxis moderna
caso de Node o TypeScript
