Condicionales
Hasta ahora, el código corre
de arriba a abajo, siempre igual
Un condicional le permite al programa
tomar decisiones distintas según el caso
if 
if (condicion) {
  // esto corre solo si condicion es true
}
const edad = 20;
if (edad >= 18) {
  console.log("Es mayor de edad");
}
Al tablero

¿Qué pasa si la condición es false?
Simplemente no entra, se salta ese bloque
else
Para cuando la condición es false
y queremos hacer otra cosa 
const edad = 15;
if (edad >= 18) {
  console.log("Es mayor de edad");
} else {
  console.log("Es menor de edad");
}
else if
Para encadenar varias condiciones,
una tras otra 
const nota = 3.2;
if (nota >= 4.5) {
  console.log("Excelente");
} else if (nota >= 3.0) {
  console.log("Aprobado");
} else {
  console.log("Reprobado");
}
Se revisan en orden
apenas una es true, las demás ya no se evalúan
Error común: pensar que revisa TODAS las condiciones. Hacer énfasis en que apenas encuentra una true, ejecuta ese bloque y se sale de todo el if/else if/else.
Al tablero

Con el código anterior, ¿qué imprime
si nota = 4.0?
"Aprobado"
Podemos combinar condicionales
con los operadores lógicos que ya vimos
(&&, ||, !) 
const edad = 20;
const tieneEntrada = true;
if (edad >= 18 && tieneEntrada) {
  console.log("Puede entrar");
}
Repaso rápido
if ejecuta un bloque si la condición es true
else cubre lo que pasa si es false
else if permite encadenar
varias condiciones seguidas

Ciclos
Con condicionales el programa ya decide
ahora falta que repita tareas
Sirven para repetir una tarea
varias veces, sin copiar y pegar código
for 
for (let i = 0; i < 5; i++) {
  console.log(i);
}
Tiene 3 partes:
inicio (let i = 0), condición (i < 5)
y paso (i++)
Mientras la condición sea true,
el ciclo se sigue repitiendo
Al tablero

for (let i = 0; i < 3; i++)
¿cuántas veces se repite?
3 veces (i vale 0, 1 y 2)
La i es solo un contador
Piénsenla como una cajita que va cambiando
en cada vuelta del ciclo 
for (let i = 0; i < 3; i++) {
  console.log(i);
}
Vamos a seguirle el rastro, vuelta por vuelta
Vuelta 1: i vale 0
se cumple i < 3, así que imprime 0
Vuelta 2: i++ convierte a i en 1
se cumple i < 3, así que imprime 1
Vuelta 3: i++ convierte a i en 2
se cumple i < 3, así que imprime 2
Vuelta 4: i++ convierte a i en 3
ya no se cumple i < 3, el ciclo termina
Error común: pensar que también imprime el 3. El for revisa la condición ANTES de correr el bloque, así que en cuanto i llega a 3, ni siquiera entra esa vuelta.
i++ es un atajo
i++ significa i = i + 1
sumar uno en cada vuelta
