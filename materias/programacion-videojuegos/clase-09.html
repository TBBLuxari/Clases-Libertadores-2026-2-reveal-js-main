Colliders: la forma con la que un objeto toca
Un Collider es una forma invisible alrededor del objeto.
Sin Collider, para el juego el objeto no existe físicamente
Collider = la forma
Rigidbody = que esa forma obedezca la física

Son dos Components distintos, y hacen falta los dos para casi todo lo de hoy
Al tablero · tipos de Collider

Box, Sphere, Capsule y Mesh
Mostrando: Inspector de un Cube con su Box Collider
Qué tipo conviene
Box, Sphere y Capsule son baratos para la computadora.
Mesh Collider es exacto pero costoso: se usa para escenarios, casi nunca para objetos que se mueven
Tres clases de objetos físicos
Estático solo Collider, sin Rigidbody: paredes, piso. No se mueve nunca
Dinámico Collider + Rigidbody: la física lo mueve y lo empuja
Kinematic Collider + Rigidbody con Is Kinematic: solo se mueve cuando lo muevan ustedes
Ejercicio (8 min): armen un pequeño corral con 4 paredes alrededor de su cubo,
y un cubo extra que el jugador pueda empujar por el piso
Colisiones con física: OnCollisionEnter
Unity avisa por sí solo cuando dos objetos con física se tocan.
Ustedes solo escriben qué hacer cuando eso pasa
Hay tres funciones especiales, y las llama Unity, no ustedes:

OnCollisionEnter: justo en el primer cuadro del choque
OnCollisionStay: en cada cuadro mientras siguen tocándose
OnCollisionExit: cuando se separan
Al tablero · un detector de choques
using UnityEngine;

public class DetectorChoque : MonoBehaviour
{
    void OnCollisionEnter(Collision collision)
    {
        Debug.Log("ENTER: choqué con " + collision.gameObject.name);
    }

    void OnCollisionStay(Collision collision)
    {
        Debug.Log("STAY: sigo tocando a " + collision.gameObject.name);
    }

    void OnCollisionExit(Collision collision)
    {
        Debug.Log("EXIT: me separé de " + collision.gameObject.name);
    }
}
Cómo usarlo
Es un script nuevo que se agrega al mismo cubo,
junto al de movimiento. Al cubo que tiene el Rigidbody
Tip de la Console
Stay escribe un mensaje por cuadro y llena todo.
Activen Collapse en la Console para que junte los repetidos con un contador
El parámetro Collision
collision trae información del choque:
collision.gameObject el objeto con el que chocamos
collision.relativeVelocity qué tan fuerte fue
collision.contacts[0].point el punto exacto donde se tocaron
Reglas para que OnCollisionEnter se dispare
Los dos objetos con Collider.
Al menos uno con Rigidbody que NO sea kinematic.
Ninguno con Is Trigger activado
Distinguir con quién chocamos: Tags
Un Tag es una etiqueta de texto en el GameObject.
Sirve para reconocer "esto es peligroso", "esto es una pared", "esto es el jugador"
Al tablero · crear un Tag

Inspector, arriba, junto a Tag: Add Tag... → + → escribir el nombre
y después seleccionarlo en el objeto
Para esta parte, creen el tag Peligro
y pónganselo a una de sus paredes 
using UnityEngine;

public class ChoqueConTag : MonoBehaviour
{
    void OnCollisionEnter(Collision collision)
    {
        if (collision.gameObject.CompareTag("Peligro"))
        {
            Debug.Log("¡Toqué algo peligroso!");
            GetComponent<Renderer>().material.color = Color.red;
        }
        else
        {
            Debug.Log("Choque normal con " + collision.gameObject.name);
        }
    }
}
Dos detalles
Se compara con CompareTag("Nombre"), que es la forma recomendada.
Si el nombre del tag está mal escrito o no existe, Unity marca un error rojo en la Console
Ejercicio (10 min): que su cubo se ponga rojo al tocar una pared peligrosa,
y que al tocar cualquier otra pared diga en la Console el nombre de esa pared
Un extra divertido: rebote
El rebote lo da el Physics Material, un asset que se arrastra al Collider.
Mostrando: Project → Create → Physics Material → Bounciness 0.8, Bounce Combine: Maximum

Colisiones sin física: Triggers
A veces no queremos que algo frene al jugador,
solo queremos enterarnos de que pasó por ahí
Ejemplos: una moneda, una llave, una zona de lava, un checkpoint, la meta del nivel
Para eso se activa Is Trigger en el Collider:
el objeto deja de ser sólido y se vuelve una zona que avisa
Al tablero · crear una moneda

Cilindro aplanado o esfera pequeña. En su Collider: Is Trigger marcado.
Sin Rigidbody en la moneda
Mostrando: Inspector de la moneda con Is Trigger activado
OnTriggerEnter, Stay y Exit
Son los mismos tres eventos, pero con Trigger en el nombre,
y el parámetro cambia: en vez de Collision recibe un Collider
OnCollisionEnter(Collision c) choque sólido. Hay rebote, empuje y fricción
OnTriggerEnter(Collider other) atravesar una zona. No frena, solo avisa
Reglas para que OnTriggerEnter se dispare
Al menos uno de los dos con Is Trigger activado.
Al menos uno de los dos con Rigidbody.
Los dos con Collider, claro

public class GirarMoneda : MonoBehaviour

    {

Creen el tag Moneda y póngansela a la moneda.

Al tablero · el texto en pantalla

Mostrando: Hierarchy → UI → Text - TextMeshPro
Ahora el script que va en el jugador:
detecta la moneda, suma, la hace desaparecer y actualiza ese texto 
using UnityEngine;
using TMPro;

public class Recolector : MonoBehaviour
{
    public TextMeshProUGUI textoMonedas; // arrastran aquí el texto desde el Inspector
    public int totalMonedas = 5;
    private int monedas = 0;

    void Start()
    {
        textoMonedas.text = "Monedas: 0 / " + totalMonedas;
    }

    void OnTriggerEnter(Collider other)
    {
        if (other.CompareTag("Moneda"))
        {
            monedas++;
            Destroy(other.gameObject);
            textoMonedas.text = "Monedas: " + monedas + " / " + totalMonedas;

            if (monedas >= totalMonedas)
                textoMonedas.text = "¡Las conseguiste todas!";
        }
    }
}
Qué hace cada parte
other es el collider de lo que entró en la zona.
Destroy(...) borra ese objeto de la escena.
textoMonedas.text cambia lo que dice el texto de la pantalla,
el que conectan en el Inspector
Ejercicio (10 min): pongan 5 monedas repartidas por su corral.
Al pasar sobre ellas deben desaparecer y el contador en pantalla tiene que subir
OnTriggerStay: zonas que hacen algo mientras estás dentro
Una zona de lava, una zona que cura, una corriente de aire:
algo que sigue pasando mientras siguen adentro
Una zona que devuelve al inicio
Una zona trigger en el piso. Creen un GameObject vacío llamado PuntoInicio
donde quieran que reaparezca el jugador 
using UnityEngine;

public class ZonaReinicio : MonoBehaviour
{
    public Transform puntoInicio; // arrastran aquí el PuntoInicio desde el Inspector

    void OnTriggerEnter(Collider other)
    {
        if (!other.CompareTag("Player")) return;

        // Si el jugador usa Character Controller, hay que apagarlo un instante
        CharacterController cc = other.GetComponent<CharacterController>();
        if (cc != null) cc.enabled = false;

        // Si el jugador usa Rigidbody, hay que frenarlo
        Rigidbody rb = other.attachedRigidbody;
        if (rb != null) rb.linearVelocity = Vector3.zero;

        other.transform.position = puntoInicio.position;

        if (cc != null) cc.enabled = true;
    }
}
Dos cosas que no son de adorno
El cubo del jugador debe tener el tag Player.
Este script va en la zona, no en el jugador,
y es la zona la que tiene el Is Trigger activado
Por qué se apaga el Character Controller
El Character Controller se defiende cuando le cambian la posición a mano.
Apagarlo un instante, mover y volver a encenderlo es la forma estándar de teletransportarlo
Ejercicio (8 min): pongan una zona de lava en una esquina de su corral.
Si el jugador la pisa, tiene que reaparecer en el inicio
Y si el jugador usa Character Controller
Trampa importante
Character Controller no dispara OnCollisionEnter.
Para los choques tiene su propia función 
using UnityEngine;

public class ChoqueController : MonoBehaviour
{
    void OnControllerColliderHit(ControllerColliderHit hit)
    {
        Debug.Log("El Character Controller tocó: " + hit.gameObject.name);
    }
}
Se llama cada vez que el Character Controller, al moverse con Move, toca un collider.
Si está quieto, no se llama
Rigidbody usa OnCollisionEnter(Collision) para choques
Character Controller usa OnControllerColliderHit para choques
Los dos usan OnTriggerEnter para zonas y monedas, sin cambiar nada
Ejercicio (6 min): si les sobra tiempo, cambien su cubo a Character Controller
y comprueben que sus monedas y su zona de lava siguen funcionando sin tocar esos scripts
Layers y trampas comunes
Layers
Una Layer es un grupo al que pertenece el objeto.
Se elige en el Inspector, arriba a la derecha, junto al Tag
En Edit → Project Settings → Physics → Layer Collision Matrix
se decide qué layers chocan con qué layers
Para qué sirve
Que los enemigos no choquen entre ellos, que las balas del jugador atraviesen al jugador,
o que una pared invisible solo frene a ciertos objetos
Cuando algo no choca: lista de revisión
1 Los dos objetos tienen Collider
2 Al menos uno tiene Rigidbody, y no está en Is Kinematic
3 Is Trigger solo está activado donde debe estarlo
4 No se mueve con transform.position un objeto que tiene Rigidbody
5 El script está en el objeto correcto y el tag existe, bien escrito
Una nota para el futuro
Si algún día hacen un juego 2D, todo esto existe igual pero con un 2 al final:
Collider2D, Rigidbody2D, OnCollisionEnter2D, OnTriggerEnter2D
