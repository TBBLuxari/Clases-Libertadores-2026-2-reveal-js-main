¿Qué es todo esto?
Visual Studio ya les generó
código automáticamente. Vamos a mirarlo 
using System;

namespace MiPrimerPrograma
{
    internal class Program
    {
        static void Main(string[] args)
        {

        }
    }
}
namespace
Es como una carpeta que agrupa
código relacionado, para que no se choquen
nombres entre proyectos distintos
class Program
Una clase es un contenedor de código
Por ahora solo identifíquenla, no la toquen
Main
Aquí es donde arranca el programa
Es lo primero que se ejecuta, siempre
Todo lo que escribamos hoy
va adentro de las llaves de Main
Al tablero

Señalar en pantalla: namespace, class, Main
Con el código generado en pantalla, señalar en vivo cada parte: el namespace, la clase Program, el método Main, y las llaves { } que delimitan cada bloque. Marcar con el cursor el espacio vacío dentro de Main como "aquí escribimos hoy".
Las llaves { } marcan dónde empieza
y dónde termina cada bloque
Cada instrucción termina en punto y coma ;
Si lo olvidan, el programa no compila
Variables
Una variable es dónde guardamos
esos datos mientras el programa está corriendo
Definición
Un espacio en la memoria del computador,
con un nombre, que guarda un dato
que puede cambiar
Piensen en una caja con una etiqueta:
la etiqueta es el nombre, adentro va el valor
Sintaxis
tipo nombre = valor; 
int edad = 20;
int: el tipo de dato
edad: el nombre de la variable
20: el valor
;: fin de la instrucción
Después se puede cambiar el valor,
sin volver a escribir el tipo 
int edad = 20;
edad = 21;
Lo que no se puede cambiar
es el tipo, una vez declarada la variable
Para ver un valor en pantalla 
Console.WriteLine(edad);

Tipos de datos
Cada variable tiene que decir
qué clase de dato va a guardar
Vamos a ver los más comunes en C#,
uno por uno, con ejemplos de la vida real
int
Números enteros, sin decimales
Ejemplo de la vida real
La edad de una persona, la cantidad de estudiantes en un salón 
int cantidadEstudiantes = 30;
double
Números con decimales,
el que se usa por defecto en C#
Ejemplo de la vida real
El promedio de notas de un semestre 
double promedio = 4.5;
float
También decimales, pero con menos precisión
Necesita el sufijo f
Ejemplo de la vida real
Se usa mucho en gráficos y videojuegos, donde
no se necesita tanta exactitud y se ahorra memoria 
float velocidad = 5.5f;
decimal
Decimales de alta precisión
Necesita el sufijo m
Ejemplo de la vida real
Dinero: cuentas bancarias, facturas, precios
(para que no haya errores de redondeo) 
decimal saldo = 150000.50m;
char
Un solo carácter, entre comillas simples
Ejemplo de la vida real
La inicial de un nombre, una talla (S, M, L) 
char inicial = 'J';
string
Texto, entre comillas dobles
Ejemplo de la vida real
Un nombre completo, un mensaje, una dirección 
string nombre = "Juan";
bool
Solo puede valer true o false
Ejemplo de la vida real
¿Aprobó la materia? ¿Está encendido el equipo? 
bool aprobado = true;
long
Como int, pero para
números enteros muy grandes
Ejemplo de la vida real
Un número de cuenta bancaria, la población mundial 
long poblacionMundial = 8000000000;
byte
Números enteros pequeños:
de 0 a 255
Ejemplo de la vida real
Un canal de color RGB (0 a 255), o la edad de alguien 
byte rojo = 255;
No hay que memorizarlos todos hoy,
con el tiempo se vuelve automático
cuál usar en cada caso
¿Cómo se llaman las variables?
En C# se usa camelCase
Primera palabra en minúscula,
las siguientes empiezan con mayúscula 
string nombreCompleto = "Juan";
int edadEstudiante = 20;
Reglas
No pueden empezar con número
Sin espacios
Mejor evitar tildes y ñ
No pueden ser una palabra reservada (como int o class)
Dato curioso
Más adelante van a ver otras convenciones:
PascalCase para clases y métodos,
_variable (guion bajo) para campos privados
Por ahora, para nuestras variables,
camelCase siempre
⚠️ OJO CON EL NOMBRE QUE LE PONEN A LAS VARIABLES ⚠️
Chiste clásico: alguien nombra mal una variable y luego "no me sirve la pechuga" o similar. Improvisar en vivo, no leer nada de un guion.
Operadores
Con las variables ya declaradas,
ahora vamos a hacer cosas con ellas
Operadores aritméticos
+ suma
- resta
* multiplicación
/ división
% módulo (el residuo de una división)
int a = 10;
int b = 3;
int suma = a + b;     // 13
int resto = a % b;    // 1
Ejemplo de la vida real
El módulo % sirve para saber, por ejemplo,
si un número es par (residuo 0 al dividir por 2)
Operadores de comparación
== ¿son iguales?
!= ¿son diferentes?
< menor que
> mayor que
<= menor o igual
>= mayor o igual
Ojo: un solo = es asignar un valor
doble == es comparar
Si vienen de JavaScript algún día,
en C# no existe el triple ===,
solo el doble == 
int edad = 20;
bool esMayorDeEdad = edad >= 18;   // true
Expresiones
Una expresión es combinar variables
y operadores en una sola línea 
int total = (precio * cantidad) - descuento;
El resultado de una expresión
se puede guardar en otra variable,
o usar directamente en un Console.WriteLine
Conversión de tipos
A veces necesitamos que un dato
cambie de tipo
Conversión implícita
C# la hace solo, cuando no hay riesgo
de perder información 
int edad = 20;
double edadDecimal = edad;   // de int a double, sin problema
Conversión explícita
Hay que forzarla nosotros, porque
se puede perder información 
double promedio = 4.8;
int promedioEntero = (int)promedio;   // 4, se pierde el decimal
Texto ↔ número
Para eso no sirve el cast con paréntesis,
se usan funciones especiales 
string textoEdad = "20";
int edad = int.Parse(textoEdad);       // texto a número

int edad2 = 20;
string textoEdad2 = edad2.ToString();  // número a texto
Estas conversiones las vamos
a practicar mucho en un rato

¿Se acuerdan del LEER del pseudocódigo?
Así se hace en C# de verdad 
string nombre = Console.ReadLine();
Console.ReadLine() siempre devuelve
texto (string), sin importar qué escriba el usuario
Si necesitamos un número,
hay que convertirlo nosotros 
Console.WriteLine("¿Cuántos años tienes?");
string textoEdad = Console.ReadLine();
int edad = int.Parse(textoEdad);
Si el usuario escribe algo
que no es un número ahí,
el programa se rompe (error de conversión)

Ejemplo completo: leer nombre y edad,
y calcular en qué año cumple 100 años
Escribir el programa en vivo en Visual Studio, proyectando pantalla. Usar Console.WriteLine para pedir los datos, Console.ReadLine para leerlos, int.Parse para convertir la edad, y una resta para calcular el año. Ejecutar y probar con datos reales de algún estudiante que se ofrezca. 
Console.WriteLine("¿Cómo te llamas?");
string nombre = Console.ReadLine();

Console.WriteLine("¿Cuántos años tienes?");
int edad = int.Parse(Console.ReadLine());

int anioActual = 2026;
int anioCien = anioActual + (100 - edad);

Console.WriteLine(nombre + ", vas a cumplir 100 años en " + anioCien);
