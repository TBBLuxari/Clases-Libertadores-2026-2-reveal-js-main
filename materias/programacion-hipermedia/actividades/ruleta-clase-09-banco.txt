BANCO DE LA RULETA DE PROGRAMACIÓN HIPERMEDIA (ifs y for)
Cada pregunta con su nivel, tiempo, puntos de control (1 punto cada uno) y solución de referencia.
Fáciles sobre 4 (6 min), normales sobre 5 (8 min), difíciles sobre 5 (10 min).
El número es el de la ruleta ("Pregunta N"). En la ruleta cada punto de control se ve con el botón Calificar o con Alt+R.
Alcance: variables, int.Parse, ReadLine, operadores, if / else / else if, && || !, % y for. Sin while, arreglos, métodos ni Math.

PREGUNTA 1  |  fácil  |  sobre 4  |  6 min

Cree un proyecto de consola nuevo. Con un ciclo for que recorra los números del 1 al 30, muestre en la consola solamente los que sean múltiplos de 3, cada uno en su propia línea. Los demás números no deben aparecer. El primero que debe salir es el 3 y el último es el 30.

Puntos de control:
  1. Proyecto nuevo que compila y recorre del 1 al 30 con un for
  2. Usa un if con el operador % para decidir cuándo mostrar el número
  3. Muestra todos los múltiplos de 3, desde el 3 hasta el 30
  4. No muestra ningún número que no sea múltiplo de 3

Solución de referencia:
for (int i = 1; i <= 30; i++)
{
    if (i % 3 == 0)
    {
        Console.WriteLine(i);
    }
}

PREGUNTA 6  |  difícil  |  sobre 5  |  10 min

Cree un proyecto de consola nuevo. Pida un número entero N. Entre 1 y N, cuente cuántos números son múltiplos de 3 o de 5, pero no de ambos a la vez, y sume esos números. Muestre "Cantidad: X" y en otra línea "Suma: Y". Con N = 15 deben salir 6 y 45.

Puntos de control:
  1. Proyecto nuevo que compila, lee N y lo convierte a int
  2. El for recorre del 1 hasta N, incluido N
  3. La condición excluye los múltiplos de ambos (el 15 no cuenta)
  4. La cantidad es correcta
  5. La suma es correcta

Solución de referencia:
int n = int.Parse(Console.ReadLine());
int cantidad = 0;
int suma = 0;
for (int i = 1; i <= n; i++)
{
    bool porTres = i % 3 == 0;
    bool porCinco = i % 5 == 0;
    if ((porTres || porCinco) && !(porTres && porCinco))
    {
        cantidad++;
        suma += i;
    }
}
Console.WriteLine("Cantidad: " + cantidad);
Console.WriteLine("Suma: " + suma);

PREGUNTA 27  |  difícil  |  sobre 5  |  10 min

Cree un proyecto de consola nuevo. Pida un número entero entre 0 y 12 y muestre su factorial con el formato "5! = 120". Calcúlelo con un for. Pruebe con 5, con 1 y con 0.

Puntos de control:
  1. Proyecto nuevo que compila, lee el número y lo convierte a int
  2. El resultado empieza en 1 (no en 0)
  3. El for multiplica los números de 1 hasta el número escrito
  4. 5! da 120
  5. 0! y 1! dan 1

Solución de referencia:
int n = int.Parse(Console.ReadLine());
int factorial = 1;
for (int i = 1; i <= n; i++)
{
    factorial *= i;
}
Console.WriteLine(n + "! = " + factorial);
