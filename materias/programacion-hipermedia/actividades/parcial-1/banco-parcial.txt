Sorteo: dos bolsas de papelitos (1 a 10 y 11 a 20), cada estudiante saca uno de cada bolsa. Corrector: node calificar.js <ficha> <ruta del proyecto>.

FICHA 1  |  El pasaje  |  ★  |  Transporte masivo

Un sistema de transporte masivo necesita calcular cuánto paga cada pasajero. El pasaje normal vale 3000.

Reglas:
  Tabla: Pasajero | Paga
    Menor de 5 años, o de 65 años o más | Nada: viaja gratis
    Estudiante | La mitad del pasaje normal
    Cualquier otro pasajero | El pasaje normal: 3000
  Tabla: Hora del día | Recargo
    6, 7 y 8 (de 6:00 a 8:59) | 20% de lo que le toca pagar
    17 y 18 (de 17:00 a 18:59) | 20% de lo que le toca pagar
    Cualquier otra hora | Sin recargo
  - Quien viaja gratis no paga nada, ni siquiera en hora pico.
  [Pista con costo, la da el profe] Cómo se calcula un recargo: El 20% de un valor es: valor × 20 ÷ 100. Ejemplo: Si a alguien le tocaba pagar 2000, el recargo del 20% son 400.

Entradas, en este orden:
  1. La edad
  2. Si es estudiante (1 = sí, 2 = no)
  3. La hora del día (de 0 a 23)

Salida:
  Pasaje: <valor>

Pruebas (entradas separadas por coma):
  1 (ejemplo). 20, 1, 7
       Pasaje: 1800
  2. 30, 2, 8
       Pasaje: 3600
  3. 4, 1, 8
       Pasaje: 0
  4. 5, 2, 19
       Pasaje: 3000
  5. 64, 1, 17
       Pasaje: 1800

Solución de referencia:
Console.WriteLine("Edad:");
int edad = int.Parse(Console.ReadLine());
Console.WriteLine("¿Es estudiante? (1 = sí, 2 = no)");
int estudiante = int.Parse(Console.ReadLine());
Console.WriteLine("Hora del día (0 a 23):");
int hora = int.Parse(Console.ReadLine());

int pasaje = 3000;

if (edad < 5 || edad >= 65)
{
    pasaje = 0;
}
else
{
    if (estudiante == 1)
    {
        pasaje = pasaje / 2;
    }

    if ((hora >= 6 && hora < 9) || (hora >= 17 && hora < 19))
    {
        pasaje = pasaje + pasaje * 20 / 100;
    }
}

Console.WriteLine("Pasaje: " + pasaje);

FICHA 2  |  La nómina semanal  |  ★  |  Taller de confecciones

Un pequeño taller de confecciones necesita calcular el pago semanal de cada empleado a partir de las horas trabajadas y del valor de la hora.

Reglas:
  Tabla: Horas de la semana | Cada hora se paga a
    De la hora 1 a la 40 | El valor de la hora
    Desde la hora 41 (horas extra) | 1,5 veces el valor de la hora
  - Bruto es lo que gana el empleado por sus horas, antes de descuentos. Neto a pagar es lo que finalmente recibe.
  - Del bruto se descuenta el 8% por salud y pensión.
  - Auxilio de transporte: si después del descuento al empleado le quedan menos de 400000, la empresa le agrega 50000. Si le quedan 400000 o más, el auxilio es 0.
  [Pista con costo, la da el profe] Cómo se calcula el descuento: El 8% de un valor es: valor × 8 ÷ 100. Ejemplo: El 8% de 200000 es 16000.

Entradas, en este orden:
  1. Las horas trabajadas en la semana
  2. El valor de la hora (siempre un múltiplo de 100)

Salida:
  Bruto: <valor>
  Descuento: <valor>
  Auxilio: <valor>
  Neto a pagar: <valor>

Pruebas (entradas separadas por coma):
  1 (ejemplo). 45, 10000
       Bruto: 475000
       Descuento: 38000
       Auxilio: 0
       Neto a pagar: 437000
  2. 40, 8000
       Bruto: 320000
       Descuento: 25600
       Auxilio: 50000
       Neto a pagar: 344400
  3. 30, 15000
       Bruto: 450000
       Descuento: 36000
       Auxilio: 0
       Neto a pagar: 414000
  4. 0, 10000
       Bruto: 0
       Descuento: 0
       Auxilio: 50000
       Neto a pagar: 50000
  5. 40, 10500
       Bruto: 420000
       Descuento: 33600
       Auxilio: 50000
       Neto a pagar: 436400

Solución de referencia:
Console.WriteLine("Horas trabajadas:");
int horas = int.Parse(Console.ReadLine());
Console.WriteLine("Valor de la hora:");
int valorHora = int.Parse(Console.ReadLine());

int normales = horas;
int extras = 0;

if (horas > 40)
{
    normales = 40;
    extras = horas - 40;
}

int bruto = normales * valorHora + extras * valorHora * 3 / 2;
int descuento = bruto * 8 / 100;
int neto = bruto - descuento;
int auxilio = 0;

if (neto < 400000)
{
    auxilio = 50000;
}

Console.WriteLine("Bruto: " + bruto);
Console.WriteLine("Descuento: " + descuento);
Console.WriteLine("Auxilio: " + auxilio);
Console.WriteLine("Neto a pagar: " + (neto + auxilio));

FICHA 3  |  Divisores y números perfectos  |  ★  |  Colegio

La profesora de matemáticas de un colegio quiere un programa que clasifique cualquier número entero positivo para usarlo en clase.

Reglas:
  - Divisor de n: número que cabe exacto en n, sin dejar residuo. Se cuentan el 1 y el propio n.
  Ejemplo: Los divisores de 10 son 1, 2, 5 y 10.
  - Primo: tiene exactamente 2 divisores (el 1 y él mismo). El 5 es primo.
  - Perfecto: si sumas sus divisores sin contar el propio número, obtienes el mismo número.
  Ejemplo: El 6 es perfecto: sus divisores menores que él son 1, 2 y 3, y 1 + 2 + 3 = 6.

Entradas, en este orden:
  1. Un número entero positivo

Salida:
  Divisores: <cantidad>
  Primo: Sí  o  Primo: No
  Perfecto: Sí  o  Perfecto: No

Pruebas (entradas separadas por coma):
  1 (ejemplo). 6
       Divisores: 4
       Primo: No
       Perfecto: Sí
  2. 1
       Divisores: 1
       Primo: No
       Perfecto: No
  3. 7
       Divisores: 2
       Primo: Sí
       Perfecto: No
  4. 28
       Divisores: 6
       Primo: No
       Perfecto: Sí
  5. 12
       Divisores: 6
       Primo: No
       Perfecto: No

Solución de referencia:
Console.WriteLine("Número:");
int n = int.Parse(Console.ReadLine());

int cantidad = 0;
int suma = 0;

for (int i = 1; i <= n; i++)
{
    if (n % i == 0)
    {
        cantidad++;

        if (i < n)
        {
            suma = suma + i;
        }
    }
}

Console.WriteLine("Divisores: " + cantidad);

if (cantidad == 2)
{
    Console.WriteLine("Primo: Sí");
}
else
{
    Console.WriteLine("Primo: No");
}

if (suma == n)
{
    Console.WriteLine("Perfecto: Sí");
}
else
{
    Console.WriteLine("Perfecto: No");
}

FICHA 4  |  El panel de jueces  |  ★  |  Federación de gimnasia

En una competencia de gimnasia, 5 jueces califican a cada atleta con un puntaje de 0 a 10. Para evitar favoritismos, de los 5 puntajes se descarta el más alto y el más bajo.

Reglas:
  - Cada uno de los 5 jueces califica con un puntaje de 0 a 10. Si un puntaje está fuera de ese rango, se le vuelve a pedir a ese mismo juez.
  - Para evitar favoritismos, no cuentan el puntaje más alto ni el más bajo. La nota final es la suma de los 3 puntajes que sí cuentan.
  - Si el más alto (o el más bajo) está repetido, solo se descarta uno de ellos.
  Ejemplo: Puntajes 7, 9, 5, 9, 8: se descartan un 9 y el 5. Cuentan el 7, el 9 y el 8.

Entradas, en este orden:
  1. El puntaje de cada uno de los 5 jueces, uno tras otro

Salida:
  Descartados: mayor <puntaje>, menor <puntaje>
  Nota final: <valor>

Pruebas (entradas separadas por coma):
  1 (ejemplo). 8, 9, 7, 10, 6
       Descartados: mayor 10, menor 6
       Nota final: 24
  2. 9, 9, 9, 9, 9
       Descartados: mayor 9, menor 9
       Nota final: 27
  3. 12, 3, 10, 7, -2, 10, 1
       Descartados: mayor 10, menor 1
       Nota final: 20
  4. 0, 0, 0, 0, 0
       Descartados: mayor 0, menor 0
       Nota final: 0
  5. 10, 10, 0, 0, 5
       Descartados: mayor 10, menor 0
       Nota final: 15

Solución de referencia:
int suma = 0;
int mayor = 0;
int menor = 10;

for (int juez = 1; juez <= 5; juez++)
{
    int puntaje;

    do
    {
        Console.WriteLine("Puntaje del juez " + juez + " (0 a 10):");
        puntaje = int.Parse(Console.ReadLine());
    }
    while (puntaje < 0 || puntaje > 10);

    suma = suma + puntaje;

    if (puntaje > mayor)
    {
        mayor = puntaje;
    }

    if (puntaje < menor)
    {
        menor = puntaje;
    }
}

Console.WriteLine("Descartados: mayor " + mayor + ", menor " + menor);
Console.WriteLine("Nota final: " + (suma - mayor - menor));

FICHA 5  |  El cronómetro del maratón  |  ★  |  Organización de carreras

Los organizadores de una maratón reciben el tiempo de cada corredor en segundos y necesitan publicarlo en formato de reloj, además de clasificarlo.

  Tabla: Dato | Cómo se muestra
    Tiempo | horas:minutos:segundos, por ejemplo 2:05:09 o 0:45:30
    Minutos y segundos | Siempre con dos cifras (05, no 5)
    Horas | Sin cero a la izquierda
  Tabla: Tiempo del corredor | Categoría
    Menos de 2 horas y 30 minutos | Élite
    2 horas y 30 minutos o más | General

Entradas, en este orden:
  1. El tiempo total del corredor, en segundos

Salida:
  Tiempo: <h>:<mm>:<ss>
  Categoría: Élite  o  Categoría: General

Pruebas (entradas separadas por coma):
  1 (ejemplo). 3909
       Tiempo: 1:05:09
       Categoría: Élite
  2. 9000
       Tiempo: 2:30:00
       Categoría: General
  3. 8999
       Tiempo: 2:29:59
       Categoría: Élite
  4. 59
       Tiempo: 0:00:59
       Categoría: Élite
  5. 14400
       Tiempo: 4:00:00
       Categoría: General

Solución de referencia:
Console.WriteLine("Tiempo en segundos:");
int total = int.Parse(Console.ReadLine());

int horas = total / 3600;
int minutos = total % 3600 / 60;

{
    Console.WriteLine("Categoría: Élite");

else
{
    Console.WriteLine("Categoría: General");
}

FICHA 6  |  La encuesta de satisfacción  |  ★  |  Cadena de restaurantes

Una cadena de restaurantes encuesta a sus clientes: cada uno califica el servicio de 1 a 5. La gerencia quiere saber qué porcentaje de clientes quedó satisfecho.

Reglas:
  Tabla: Calificación | El cliente queda
    1 o 2 | Insatisfecho
    3 | Neutral
    4 o 5 | Satisfecho
  - Cuántos clientes respondieron: al menos 1 (si no, se vuelve a preguntar). Una calificación fuera de 1 a 5 se vuelve a pedir al mismo cliente y no cuenta como un cliente más.
  - El porcentaje de cada grupo es la parte del total de clientes que ese grupo representa.
  Tabla: Satisfechos | Resultado
    80% o más | Excelente
    De 50% a menos de 80% | Aceptable
    Menos de 50% | Crítico
  - Para decidir el resultado se usa el porcentaje de satisfechos ya sin decimales. Por eso los tres porcentajes pueden no sumar 100.
  [Pista con costo, la da el profe] Cómo se calcula un porcentaje: El porcentaje de un grupo es: cantidad del grupo × 100 ÷ total de clientes. Ejemplo: 3 satisfechos de 8 clientes: 3 × 100 ÷ 8 = 37%.

Entradas, en este orden:
  1. Cuántos clientes respondieron
  2. La calificación de cada cliente, uno tras otro

Salida:
  Satisfechos: <n>%
  Neutrales: <n>%
  Insatisfechos: <n>%
  Resultado: Excelente  o  Aceptable  o  Crítico

Pruebas (entradas separadas por coma):
  1 (ejemplo). 5, 5, 4, 3, 2, 5
       Satisfechos: 60%
       Neutrales: 20%
       Insatisfechos: 20%
       Resultado: Aceptable
  2. 1, 5
       Satisfechos: 100%
       Neutrales: 0%
       Insatisfechos: 0%
       Resultado: Excelente
  3. 10, 5, 5, 4, 4, 4, 5, 4, 5, 3, 2
       Satisfechos: 80%
       Neutrales: 10%
       Insatisfechos: 10%
       Resultado: Excelente
  4. 3, 9, 4, 0, 5, 1
       Satisfechos: 66%
       Neutrales: 0%
       Insatisfechos: 33%
       Resultado: Aceptable
  5. 4, 1, 2, 3, 5
       Satisfechos: 25%
       Neutrales: 25%
       Insatisfechos: 50%
       Resultado: Crítico

Solución de referencia:
int total;

do
{
    Console.WriteLine("¿Cuántos clientes respondieron?");
    total = int.Parse(Console.ReadLine());
}
while (total < 1);

int satisfechos = 0;
int neutrales = 0;
int insatisfechos = 0;

for (int i = 1; i <= total; i++)
{
    int calificacion;

    do
    {
        Console.WriteLine("Calificación del cliente " + i + " (1 a 5):");
        calificacion = int.Parse(Console.ReadLine());
    }
    while (calificacion < 1 || calificacion > 5);

    if (calificacion >= 4)
    {
        satisfechos++;
    }
    else if (calificacion == 3)
    {
        neutrales++;
    }
    else
    {
        insatisfechos++;
    }
}

int porcentajeSatisfechos = satisfechos * 100 / total;
int porcentajeNeutrales = neutrales * 100 / total;
int porcentajeInsatisfechos = insatisfechos * 100 / total;

Console.WriteLine("Satisfechos: " + porcentajeSatisfechos + "%");
Console.WriteLine("Neutrales: " + porcentajeNeutrales + "%");
Console.WriteLine("Insatisfechos: " + porcentajeInsatisfechos + "%");

if (porcentajeSatisfechos >= 80)
{
    Console.WriteLine("Resultado: Excelente");
}
else if (porcentajeSatisfechos >= 50)
{
    Console.WriteLine("Resultado: Aceptable");
}
else
{
    Console.WriteLine("Resultado: Crítico");
}

FICHA 7  |  El inventario de la bodega  |  ★  |  Distribuidora

Una distribuidora lleva el inventario de un producto. Parte de un stock inicial y registra los movimientos del día: las entradas llegan de los proveedores y las salidas se despachan a los clientes.

Reglas:
  - El stock inicial tiene que ser mayor que 0; si no, se vuelve a preguntar.
  Tabla: Movimiento | Significa
    Número positivo | Entrada: llegan unidades del proveedor
    Número negativo | Salida: se despachan unidades a un cliente
    0 | Se terminó el día
  - No se puede despachar más de lo que hay. Una salida mayor que el stock disponible en ese momento se rechaza: el stock no cambia y se cuenta como salida rechazada.
  Ejemplo: Stock 60. Llegan 25 y hay 85. Piden sacar 90: se rechaza y siguen 85. Piden sacar 40 y quedan 45.
  - Al final, si el stock quedó por debajo del 20% del stock inicial, se muestra una alerta. Si no, la alerta no aparece.
  [Pista con costo, la da el profe] Cómo se calcula un porcentaje: El 20% de un valor es: valor × 20 ÷ 100. Ejemplo: Con un stock inicial de 150, el 20% son 30: la alerta sale si al final quedan menos de 30.

Entradas, en este orden:
  1. El stock inicial
  2. Los movimientos del día, uno tras otro, hasta que escriban 0

Salida:
  Stock final: <n>
  Salidas rechazadas: <n>
  Alerta: stock bajo   (solo si corresponde)

Pruebas (entradas separadas por coma):
  1 (ejemplo). 100, -30, 50, -200, -90, 0
       Stock final: 30
       Salidas rechazadas: 1
  2. 50, 0
       Stock final: 50
       Salidas rechazadas: 0
  3. 100, -90, 0
       Stock final: 10
       Salidas rechazadas: 0
       Alerta: stock bajo
  4. 100, -80, 0
       Stock final: 20
       Salidas rechazadas: 0
  5. 200, 10, -250, -300, 0
       Stock final: 210
       Salidas rechazadas: 2

Solución de referencia:
int inicial;

do
{
    Console.WriteLine("Stock inicial:");
    inicial = int.Parse(Console.ReadLine());
}
while (inicial < 1);

int stock = inicial;
int rechazadas = 0;

Console.WriteLine("Movimiento (positivo entrada, negativo salida, 0 para terminar):");
int movimiento = int.Parse(Console.ReadLine());

while (movimiento != 0)
{
    if (movimiento > 0)
    {
        stock = stock + movimiento;
    }
    else
    {
        int salida = -movimiento;

        if (salida > stock)
        {
            rechazadas++;
        }
        else
        {
            stock = stock - salida;
        }
    }

    Console.WriteLine("Movimiento (positivo entrada, negativo salida, 0 para terminar):");
    movimiento = int.Parse(Console.ReadLine());
}

Console.WriteLine("Stock final: " + stock);
Console.WriteLine("Salidas rechazadas: " + rechazadas);

if (stock < inicial * 20 / 100)
{
    Console.WriteLine("Alerta: stock bajo");
}

FICHA 8  |  La factura con IVA  |  ★  |  Minimercado

Un minimercado necesita un programa para facturar. El cajero registra los productos de la compra uno por uno, cada uno con su categoría y su precio, y al final se imprime la factura.

Reglas:
  - El cajero registra cada producto con su categoría y su precio. La compra termina cuando la categoría es 0.
  Tabla: Categoría | Tipo de producto | IVA
    1 | Alimentos | 5%
    2 | General | 19%
    3 | Exento | Sin IVA
  - Si la categoría no es 0, 1, 2 ni 3, se muestra "Categoría inválida", no se pregunta el precio y ese producto no se registra.
  - El IVA de cada producto es el porcentaje de su categoría aplicado al precio de ese producto.
  - Si el subtotal (la suma de los precios, sin IVA) supera 200000, el cliente recibe un descuento del 10% del subtotal.
  - Subtotal: la suma de los precios, sin IVA. IVA: la suma del IVA de todos los productos (el descuento no lo cambia). Total: lo que finalmente paga el cliente.
  [Pista con costo, la da el profe] Cómo se calcula el IVA: El IVA de un producto es: precio × porcentaje ÷ 100. Ejemplo: Un producto de 30000 de la categoría 1 (5%) genera 1500 de IVA.
  [Pista con costo, la da el profe] Cómo se calcula el descuento: El descuento es: subtotal × 10 ÷ 100. Ejemplo: Con un subtotal de 300000, el descuento es 30000.

Entradas, en este orden:
  1. Por cada producto: la categoría y luego el precio. La compra termina cuando la categoría es 0

Salida:
  Productos: <cantidad>
  Subtotal: <valor>
  IVA: <valor>
  Descuento: <valor>
  Total: <valor>

Pruebas (entradas separadas por coma):
  1 (ejemplo). 1, 40000, 2, 100000, 3, 20000, 0
       Productos: 3
       Subtotal: 160000
       IVA: 21000
       Descuento: 0
       Total: 181000
  2. 2, 150000, 2, 100000, 0
       Productos: 2
       Subtotal: 250000
       IVA: 47500
       Descuento: 25000
       Total: 272500
  3. 7, 1, 1000, 0
       Productos: 1
       Subtotal: 1000
       IVA: 50
       Descuento: 0
       Total: 1050
  4. 0
       Productos: 0
       Subtotal: 0
       IVA: 0
       Descuento: 0
       Total: 0
  5. 2, 200000, 0
       Productos: 1
       Subtotal: 200000
       IVA: 38000
       Descuento: 0
       Total: 238000

Solución de referencia:
int productos = 0;
int subtotal = 0;
int iva = 0;

Console.WriteLine("Categoría (1 alimentos, 2 general, 3 exento, 0 para terminar):");
int categoria = int.Parse(Console.ReadLine());

while (categoria != 0)
{
    if (categoria < 0 || categoria > 3)
    {
        Console.WriteLine("Categoría inválida");
    }
    else
    {
        Console.WriteLine("Precio:");
        int precio = int.Parse(Console.ReadLine());

        productos++;
        subtotal = subtotal + precio;

        if (categoria == 1)
        {
            iva = iva + precio * 5 / 100;
        }
        else if (categoria == 2)
        {
            iva = iva + precio * 19 / 100;
        }
    }

    Console.WriteLine("Categoría (1 alimentos, 2 general, 3 exento, 0 para terminar):");
    categoria = int.Parse(Console.ReadLine());
}

int descuento = 0;

if (subtotal > 200000)
{
    descuento = subtotal * 10 / 100;
}

int total = subtotal + iva - descuento;

Console.WriteLine("Productos: " + productos);
Console.WriteLine("Subtotal: " + subtotal);
Console.WriteLine("IVA: " + iva);
Console.WriteLine("Descuento: " + descuento);
Console.WriteLine("Total: " + total);

FICHA 9  |  El plan de producción  |  ★  |  Fábrica de empaques

Una fábrica planea su año. Sabe cuántas unidades producirá en enero y cuántas necesita producir al mes para cumplir su meta. Cada mes la producción crece, pero la planta tiene un tope.

Reglas:
  - El mes 1 se produce la cantidad indicada (entre 1 y 5000). A partir del mes 2, cada mes la producción crece un 5% respecto al mes anterior.
  - La planta tiene un tope: nunca puede producir más de 5000 unidades en un mes.
  - El programa reporta: lo producido en total durante los 12 meses; el primer mes en que se llega a la meta mensual o se supera (si nunca ocurre, se avisa); y cuántos meses se produjo exactamente 5000.
  [Pista con costo, la da el profe] Cómo se calcula el crecimiento: El 5% de un valor es: valor × 5 ÷ 100. Ejemplo: Un mes de 2000 unidades crece 100, y el mes siguiente es de 2100.

Entradas, en este orden:
  1. Las unidades del mes 1
  2. La meta mensual

Salida:
  Total del año: <n>
  Primer mes que alcanza la meta: <mes>   (o  Meta no alcanzada)
  Meses a capacidad máxima: <n>

Pruebas (entradas separadas por coma):
  1 (ejemplo). 1000, 1500
       Total del año: 15883
       Primer mes que alcanza la meta: 10
       Meses a capacidad máxima: 0
  2. 4000, 4500
       Total del año: 57101
       Primer mes que alcanza la meta: 4
       Meses a capacidad máxima: 7
  3. 5000, 100
       Total del año: 60000
       Primer mes que alcanza la meta: 1
       Meses a capacidad máxima: 12

    else
    {
        Console.WriteLine("Cantidad de entradas:");
        int entradas = int.Parse(Console.ReadLine());

        int valor = entradas * 12000;

        if (entradas >= 4)
        {
            valor = valor - valor * 10 / 100;
        }

        recaudado = recaudado + valor;

        if (pelicula == 1)
        {
            entradas1 = entradas1 + entradas;
        }
        else if (pelicula == 2)
        {
            entradas2 = entradas2 + entradas;
        }
        else
        {
            entradas3 = entradas3 + entradas;
        }
    }

    Console.WriteLine("Película (1, 2, 3 o 0 para cerrar):");
    pelicula = int.Parse(Console.ReadLine());
}

Console.WriteLine("Recaudado: " + recaudado);

int masVendida = 1;
int mayor = entradas1;

if (entradas2 > mayor)
{
    masVendida = 2;
    mayor = entradas2;
}

if (entradas3 > mayor)
{
    masVendida = 3;
    mayor = entradas3;
}

if (mayor == 0)
{
    Console.WriteLine("Más vendida: ninguna");
}
else
{
    Console.WriteLine("Más vendida: Película " + masVendida + " (entradas: " + mayor + ")");
}

FICHA 18  |  El histograma de ventas  |  ★★  |  Tienda de barrio

El dueño de una tienda anota cuántas unidades de su producto estrella vendió cada día de la semana (de 1 a 9) y quiere verlo dibujado con asteriscos para comparar los días de un vistazo.

Reglas:
  - Se piden las ventas de 7 días, una por una. Cada venta debe estar entre 1 y 9; si no, se vuelve a pedir el dato de ese mismo día.
  Ejemplo: La barra de un día con 5 unidades vendidas se ve así: *****
  - Para cada día se muestra una línea con el número del día y su barra: tantos asteriscos como unidades se vendieron.
  - Al final se dice cuál fue el mejor día (el de más ventas). Si hay empate, es el primero que alcanzó ese máximo.

Entradas, en este orden:
  1. Las ventas de cada uno de los 7 días, uno tras otro

Salida:
  Día 1: <asteriscos>
  (una línea así por cada uno de los 7 días)
  Mejor día: <día> (ventas: <unidades>)

Pruebas (entradas separadas por coma):
  1 (ejemplo). 3, 5, 2, 9, 1, 4, 6
       Día 1: ***
       Día 2: *****
       Día 3: **
       Día 4: *********
       Día 5: *
       Día 6: ****
       Día 7: ******

  2. 1, 1, 1, 1, 1, 1, 1
       Día 1: *
       Día 2: *
       Día 3: *
       Día 4: *
       Día 5: *
       Día 6: *
       Día 7: *
       Mejor día: 1 (ventas: 1)
  3. 9, 9, 9, 9, 9, 9, 9
       Día 1: *********
       Día 2: *********
       Día 3: *********
       Día 4: *********
       Día 5: *********
       Día 6: *********
       Día 7: *********
       Mejor día: 1 (ventas: 9)
  4. 12, 2, 8, 0, 4, 4, 7, 1, 3
       Día 1: **
       Día 2: ********
       Día 3: ****
       Día 4: ****
       Día 5: *******
       Día 6: *
       Día 7: ***

  5. 5, 4, 3, 2, 1, 2, 3
       Día 1: *****
       Día 2: ****
       Día 3: ***
       Día 4: **
       Día 5: *
       Día 6: **

int mejorDia = 1;

        mejorVenta = ventas;
        mejorDia = dia;
    }
}

Console.WriteLine("Mejor día: " + mejorDia + " (ventas: " + mejorVenta + ")");

FICHA 19  |  El calendario del mes  |  ★★  |  Editorial de agendas

Una editorial de agendas quiere generar automáticamente la página de calendario de cada mes. Solo conoce cuántos días tiene el mes y en qué día de la semana cae el día 1.

Reglas:
  Tabla: Dato | Valores

  Ejemplo: Si el mes empieza en miércoles (3), el día 1 queda debajo de Mi. Fíjate en el ejemplo.

Entradas, en este orden:
  1. Cuántos días tiene el mes
  2. El día de la semana en que empieza (1 = lunes ... 7 = domingo)

Salida:
  El encabezado y luego las filas del calendario (ver ejemplo)

FICHA 20  |  El cierre de las sucursales  |  ★★  |  Cadena de tiendas

Una cadena de tiendas cierra el mes: cada sucursal reporta sus ventas de cada día y la empresa calcula la comisión de cada una y cuál vendió más.

Reglas:
  Tabla: Ventas de la sucursal en el mes | Comisión
    Hasta 5000000 | 3%
    Lo que pase de 5000000 | 5% (solo sobre ese excedente)
  Ejemplo: Con 8000000 de ventas: 3% sobre los primeros 5000000 y 5% sobre los 3000000 restantes.
  - Se pregunta cuántas sucursales hay y cuántos días se reportan (los dos al menos 1; si no, se vuelve a preguntar). Luego se piden las ventas de cada día, sucursal por sucursal.
  - El total de una sucursal son sus ventas de todos los días reportados. La mejor sucursal es la de mayor total; si hay empate, la de número menor.
  [Pista con costo, la da el profe] Cómo se calcula un porcentaje: El X% de un valor es: valor × X ÷ 100. Ejemplo: El 3% de 4000000 es 120000.

Entradas, en este orden:
  1. Cuántas sucursales hay
  2. Cuántos días se reportan
  3. Las ventas de cada día de la sucursal 1, luego las de la sucursal 2, y así

Salida:
  Sucursal <n>: total <valor>, comisión <valor>   (una línea por sucursal)
  Mejor sucursal: <n> con <total>

Pruebas (entradas separadas por coma):
  1 (ejemplo). 2, 3, 2000000, 1500000, 2500000, 1000000, 800000, 700000
       Sucursal 1: total 6000000, comisión 200000
       Sucursal 2: total 2500000, comisión 75000
       Mejor sucursal: 1 con 6000000
  2. 1, 1, 5000000
       Sucursal 1: total 5000000, comisión 150000
       Mejor sucursal: 1 con 5000000
  3. 3, 2, 100, 200, 5000000, 1, 0, 300
       Sucursal 1: total 300, comisión 9
       Sucursal 2: total 5000001, comisión 150000
       Sucursal 3: total 300, comisión 9
       Mejor sucursal: 2 con 5000001
  4. 2, 2, 1000, 1000, 1000, 1000
       Sucursal 1: total 2000, comisión 60
       Sucursal 2: total 2000, comisión 60
       Mejor sucursal: 1 con 2000
  5. 1, 4, 3000000, 3000000, 0, 1
       Sucursal 1: total 6000001, comisión 200000
       Mejor sucursal: 1 con 6000001

Solución de referencia:
int sucursales;

do
{
    Console.WriteLine("Cantidad de sucursales:");
    sucursales = int.Parse(Console.ReadLine());
}
while (sucursales < 1);

int dias;

do
{
    Console.WriteLine("Cantidad de días:");
    dias = int.Parse(Console.ReadLine());
}
while (dias < 1);

int mejorSucursal = 0;
int mayorTotal = -1;

for (int s = 1; s <= sucursales; s++)
{
    int total = 0;

    for (int d = 1; d <= dias; d++)
    {
        Console.WriteLine("Ventas de la sucursal " + s + ", día " + d + ":");
        total = total + int.Parse(Console.ReadLine());
    }

    int comision;

    if (total <= 5000000)
    {
        comision = total * 3 / 100;
    }
    else
    {
        comision = 5000000 * 3 / 100 + (total - 5000000) * 5 / 100;
    }

    Console.WriteLine("Sucursal " + s + ": total " + total + ", comisión " + comision);

    if (total > mayorTotal)
    {
        mayorTotal = total;
        mejorSucursal = s;
    }
}

Console.WriteLine("Mejor sucursal: " + mejorSucursal + " con " + mayorTotal);
