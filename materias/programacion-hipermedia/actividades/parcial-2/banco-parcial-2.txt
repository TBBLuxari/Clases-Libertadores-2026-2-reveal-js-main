FICHA 1  |  El combo de pan  |  ★  |  Panadería

Una panadería de barrio vende panes de dos tipos y hace descuento cuando el pedido es grande.

Reglas:
  Tabla: Tipo de pan | Precio unidad
    1 = Blanco | 650
    2 = Integral | 800
  - Si el pedido es de 12 panes o más (una docena o más), se descuenta el 10% del total.
  - El tipo de pan siempre es 1 o 2; no hay que validar otros valores.

Entradas, en este orden:
  1. La cantidad de panes
  2. El tipo de pan (1 = blanco, 2 = integral)

Salida:
  Total: <valor>

Pruebas (entradas separadas por coma, en el orden de arriba):
  1 (ejemplo). 1, 1
       Total: 650
  2. 12, 1
       Total: 7020
  3. 5, 2
       Total: 4000
  4. 20, 2
       Total: 14400
  5. 11, 1
       Total: 7150

Solución de referencia:
Console.WriteLine("Cantidad de panes:");
int cantidad = int.Parse(Console.ReadLine());
Console.WriteLine("Tipo (1 = blanco, 2 = integral):");
int tipo = int.Parse(Console.ReadLine());

int precio = 650;
if (tipo == 2) { precio = 800; }

int total = precio * cantidad;
if (cantidad >= 12)
{
    total = total - total * 10 / 100;
}

Console.WriteLine("Total: " + total);

FICHA 2  |  El parqueadero por horas  |  ★  |  Parqueadero

Un parqueadero cobra una tarifa fija por la primera hora y un valor adicional por cada hora completa de más. Los minutos que sobren después de la última hora completa también se cobran, pero solo si pasan de 15 minutos.

Reglas:
  Tabla: Tiempo | Cobro
    Primera hora | 4000
    Cada hora adicional completa | 3000
    Minutos sueltos después de la última hora (16 o más) | Se cobra como una hora adicional más: 3000
    Minutos sueltos de 15 o menos | No se cobran
  - Si el vehículo se queda menos de una hora en total (0 horas completas), igual paga la tarifa de la primera hora.

Entradas, en este orden:
  1. Las horas completas que estuvo el vehículo (puede ser 0)
  2. Los minutos sueltos, además de esas horas (de 0 a 59)

Salida:
  Total: <valor>

Pruebas (entradas separadas por coma, en el orden de arriba):
  1 (ejemplo). 0, 0
       Total: 4000
  2. 0, 20
       Total: 7000
  3. 2, 10
       Total: 10000
  4. 1, 16
       Total: 10000
  5. 0, 15
       Total: 4000

Solución de referencia:
Console.WriteLine("Horas completas:");
int horas = int.Parse(Console.ReadLine());
Console.WriteLine("Minutos sueltos:");
int minutos = int.Parse(Console.ReadLine());

int total = 4000;
int extra = horas - 1;
if (extra < 0) { extra = 0; }
total = total + extra * 3000;

if (minutos > 15)
{
    total = total + 3000;
}

Console.WriteLine("Total: " + total);

    return recargo;
}

  - Todos los pares de la compra tienen el mismo precio normal.

  1. El precio normal de un par
  2. La cantidad de pares que compró (1 o más)

  Total: <valor>

Pruebas (entradas separadas por coma, en el orden de arriba):
  1 (ejemplo). 80000, 1
       Total: 80000
  2. 80000, 2
       Total: 120000

  4. 80000, 4

  5. 80000, 5
       Total: 288000

Solución de referencia:
Console.WriteLine("Precio normal de un par:");
int precio = int.Parse(Console.ReadLine());
Console.WriteLine("Cantidad de pares:");
int pares = int.Parse(Console.ReadLine());

int total = 0;
for (int i = 1; i <= pares; i++)
{
    total = total + PrecioDelPar(precio, i);
}

static int PrecioDelPar(int precioNormal, int numeroDePar)
{
    if (numeroDePar == 1) { return precioNormal; }
    if (numeroDePar == 2) { return precioNormal - precioNormal * 50 / 100; }
    return precioNormal - precioNormal * 30 / 100;
}

FICHA 14  |  La compra del supermercado  |  ★★  |  Supermercado

Un supermercado separa sus productos en dos categorías: básicos (sin IVA) y los demás (con IVA del 19%). El cliente va a ingresar varios productos, uno por uno. El programa debe guardar los precios en un arreglo (y las categorías en otro arreglo del mismo tamaño) antes de calcular el total.

Reglas:
  Tabla: Categoría | ¿Tiene IVA?
    1 = Básico | No
    2 = Otro | Sí, 19%
  - Primero se leen todos los productos y se guardan en los arreglos; el total se calcula después, recorriendo esos arreglos.


Entradas, en este orden:
  1. La cantidad de productos que va a ingresar
  2. Por cada producto, en orden: su precio y su categoría (1 o 2)

Salida:
  Total: <valor>

Pruebas (entradas separadas por coma, en el orden de arriba):
  1 (ejemplo). 2, 10000, 1, 20000, 2
       Total: 33800
  2. 3, 5000, 1, 5000, 1, 5000, 2
       Total: 15950
  3. 1, 100000, 2
       Total: 119000
  4. 4, 1000, 1, 2000, 1, 3000, 2, 4000, 2
       Total: 11330
  5. 2, 50000, 2, 10000, 1
       Total: 69500

Solución de referencia:
Console.WriteLine("Cantidad de productos:");
int n = int.Parse(Console.ReadLine());

int[] precios = new int[n];
int[] categorias = new int[n];

for (int i = 0; i < n; i++)
{
    Console.WriteLine("Precio del producto:");
    precios[i] = int.Parse(Console.ReadLine());
    Console.WriteLine("Categoría (1 = básico, 2 = otro):");
    categorias[i] = int.Parse(Console.ReadLine());
}

int total = 0;
for (int i = 0; i < n; i++)
{
    total = total + PrecioConIva(precios[i], categorias[i]);
}

Console.WriteLine("Total: " + total);

static int PrecioConIva(int precio, int categoria)
{
    if (categoria == 1) { return precio; }
    return precio + precio * 19 / 100;
}

  - Esta regla de los 50 km se aplica por separado en cada tramo, no al acumulado del viaje completo.


Entradas, en este orden:
  1. La cantidad de tramos del viaje
  2. Por cada tramo, en orden: los kilómetros de ese tramo

Salida:
  Total: <valor>

Pruebas (entradas separadas por coma, en el orden de arriba):
  1 (ejemplo). 1, 40
       Total: 6000
  2. 1, 80
       Total: 10500
  3. 2, 30, 60
       Total: 13000
  4. 3, 50, 20, 100
       Total: 23000
  5. 2, 90, 10
       Total: 13000

Solución de referencia:
Console.WriteLine("Cantidad de tramos:");
int tramos = int.Parse(Console.ReadLine());

int[] kms = new int[tramos];
for (int i = 0; i < tramos; i++)
{
    Console.WriteLine("Kilómetros de este tramo:");
    kms[i] = int.Parse(Console.ReadLine());
}

int total = 0;
for (int i = 0; i < tramos; i++)
{
    total = total + CostoDelTramo(kms[i]);
}

Console.WriteLine("Total: " + total);

static int CostoDelTramo(int km)
{
    if (km <= 50) { return km * 150; }
    return 50 * 150 + (km - 50) * 100;
}
