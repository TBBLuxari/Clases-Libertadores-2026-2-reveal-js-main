Repaso del corte
Algoritmos
Una secuencia de pasos, ordenados y precisos,
para resolver un problema o cumplir una tarea
Entrada: lo que necesita para empezar
Proceso: los pasos que lo transforman
Salida: el resultado final
Un buen algoritmo es finito, preciso
y ordenado, y siempre tiene un resultado
Pseudocódigo
INICIO / FIN — marcan el comienzo y el final
LEER — pedir un dato de entrada
ESCRIBIR — mostrar un resultado
INICIO
  LEER cantidad de empanadas
  LEER precio de una empanada
  MULTIPLICAR cantidad por precio
  ESCRIBIR el total a pagar
FIN
LEER es la entrada, MULTIPLICAR es el proceso,
ESCRIBIR es la salida. Las tres partes de siempre
Diagramas de flujo
Recordatorio
Óvalo: inicio y fin · Paralelogramo: entrada/salida
Rectángulo: un paso · Rombo: decisión, dos caminos
Las flechas nunca quedan sueltas,
todo se conecta, y el flujo va de arriba hacia abajo

Variables y tipos de dato
tipo nombre = valor; 
int edad = 20;
El valor se puede cambiar después,
el tipo no
int: enteros
double / float / decimal: decimales
char: un solo carácter · string: texto
bool: true / false
float
Necesita el sufijo f    decimal Necesita el sufijo m 
float velocidad = 5.5f;
decimal saldo = 150000.50m;
¿Cuál se usa para dinero?
decimal, para evitar errores de redondeo
camelCase
Primera palabra en minúscula,
las siguientes empiezan con mayúscula 
string nombreCompleto = "Juan";
int edadEstudiante = 20;
No pueden empezar con número
Sin espacios, mejor sin tildes ni ñ
No pueden ser una palabra reservada
Operadores
+ - * / aritméticos
% módulo: el residuo de una división
== != < > <= >= comparación
Ojo: un solo = es asignar,
doble == es comparar 
int a = 10;
int b = 3;
int resto = a % b;          // 1
bool esMayor = a > b * 4;   // false
Conversión de tipos
Implícita
C# la hace sola, sin riesgo de perder información 
int edad = 20;
double edadDecimal = edad;
Explícita (cast)
Hay que forzarla, se puede perder el decimal 
double promedio = 4.8;
int promedioEntero = (int)promedio;   // 4
Texto ↔ número 
int edad = int.Parse("20");
string textoEdad = edad.ToString();
Datos por consola
Console.ReadLine() siempre devuelve
texto (string), sin importar qué escriba el usuario 
Console.WriteLine("¿Cuántos años tienes?");
int edad = int.Parse(Console.ReadLine());
Console.WriteLine("Tienes " + edad + " años");
Si el usuario escribe algo que no es un número
ahí, el programa se rompe (error de conversión)
Con esto, ya quedó todo el corte repasado
